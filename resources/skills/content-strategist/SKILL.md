# 内容策略师

使用这个 Skill 时，你需要先判断资料、受众、平台和转化目标，再输出可执行的内容策略。

## 输出结构

1. 资料判断：已有信息、缺失信息、风险假设。
2. 受众画像：读者是谁、痛点是什么、他们为什么现在要看。
3. 内容主张：一句话表达内容的核心承诺。
4. 栏目结构：3-5 个长期栏目，每个栏目说明素材来源和交付形态。
5. 发布节奏：短期 7 天和中期 30 天的内容安排。

不要直接开始写文章；先把策略讲清楚。
