## 排版核心方法论：BRL三维排版系统

```
B - Breath（呼吸感）：留白与间距，让眼睛不累
R - Rhythm（节奏感）：长短交替、疏密变化，让阅读有韵律
L - Layer（层次感）：标题→正文→辅助，让信息有主次
```

---

## 第一维：呼吸感（Breath）

### 段落间距系统

```
段落间距黄金比例：

标题与正文间距  ＝ 1.5倍行距（明确分隔，不粘连）
段落间间距      ＝ 1倍空行（段与段之间有呼吸）
段内行距        ＝ 1.75-2倍（行间透气）
列表项间距      ＝ 0.5倍空行（紧凑但不拥挤）
板块间间距      ＝ 2倍空行 + 分隔符（明确的章节切换）
```

### 段落长度控制

```
黄金段落法则：

每段 3-5 行（移动端）/ 4-6 行（PC端）
├── 超过6行必须拆段
├── 单句成段 = 强调（每篇最多用2-3次）
├── 连续3段以上等长 = 节奏单调，需要打破
└── 关键信息段落前后各留一个空行
```

### 留白策略

```
四种留白场景：

1. 结构留白：章节之间的大留白，用分隔线+空行
2. 段落留白：段与段之间的标准空行
3. 强调留白：重要句子/金句前后的额外空行，制造"聚光灯"效果
4. 呼吸留白：长段落之后的空行，让读者喘口气
```

## 第二维：节奏感（Rhythm）

### 内容节奏公式

```
黄金节奏 = 叙述段 + 短句/金句 + 列表/数据 + 过渡句 （循环）

节奏变化手法：
├── 长段+短句交替：3-5行段落后接一句1行金句
├── 文字+视觉交替：每2-3段插入一个视觉元素（图/引用框/列表/分隔线）
├── 密集+留白交替：信息密集段后给一个大留白
└── 正文+互动交替：阅读段后插入一个提问/互动句
```

### 视觉断点设计

```
每800-1200字设置一个视觉断点：

视觉断点类型（按冲击力排序）：
1. 🖼 配图（最强断点）
2. 📊 数据图表/信息图
3. 💬 引用框/金句卡片
4. 📋 列表/步骤
5. ── 分隔线（最弱断点）
6. 🔤 加粗/变色关键词（段内微断点）
```

### 开头与结尾节奏

```
开头三段定生死：
├── 第1段：钩子（1-2句，制造悬念/共鸣/冲突）
├── 第2段：展开（3-4句，交代背景/承接钩子）
└── 第3段：承诺（1-2句，告诉读者这篇文章能给你什么）

结尾三段做收束：
├── 倒数第3段：总结核心观点
├── 倒数第2段：金句/升华（适合截图传播）
└── 最后一段：行动号召/互动引导
```

## 第三维：层次感（Layer）

### 标题层级系统

```
四级标题体系：

H1 ━━ 文章大标题（全文唯一）
│     字号：最大 | 加粗 | 居中或左对齐
│     功能：概括全文主题，吸引点击
│
├── H2 ── 章节标题（3-5个/篇）
│         字号：次大 | 加粗 | 左对齐
│         前缀：序号/emoji/图标（可选）
│         功能：划分文章大板块
│
│   ├── H3 ── 小节标题（每章2-4个）
│   │         字号：正文偏大 | 加粗
│   │         功能：细分章节内容
│   │
│   │   └── H4 ── 要点标题（可选）
│   │               字号：正文大小 | 加粗
│   │               功能：列表式要点的小标题
│
│  （H2和H2之间用分隔线或大留白区分）
```

### 标题前缀风格库

```
风格A - 数字序号型（理性/教程/干货）
  01 | 第一章节标题
  02 | 第二章节标题
  03 | 第三章节标题

风格B - Emoji标记型（活泼/公众号/小红书）
  🔥 第一章节标题
  💡 第二章节标题
  ✨ 第三章节标题

风格C - 符号装饰型（简约/知乎/专业）
  ▎第一章节标题
  ▎第二章节标题
  ▎第三章节标题

风格D - 纯净型（高端/极简/文学）
  第一章节标题
  ——
  第二章节标题
  ——

风格E - 括号标注型（结构化/报告/分析）
  【洞察】第一章节标题
  【策略】第二章节标题
  【执行】第三章节标题
```

### 强调层级系统

```
四级强调体系（从强到弱）：

Level 1 - 金句框/引用块
  ┃ 最重要的一句话放在这里
  适用：核心观点、金句、数据结论（每篇1-3个）

Level 2 - 加粗+变色
  **关键词**用加粗配合主题色
  适用：核心概念、重要数据、关键动词（每段1-2个）

Level 3 - 纯加粗
  **一般强调词**
  适用：次要概念、对比项、小标题内关键词

Level 4 - 斜体/下划线
  *补充说明*
  适用：注释、备注、引用来源

⚠️ 强调滥用 = 没有强调。每段加粗不超过2处，每篇金句框不超过3个。
```

### 输出模式1：Markdown格式

```
适用场景：通用内容、知乎、头条、博客、文档
输出内容：直接输出排版好的Markdown文本
优势：通用性强、可转换为多种格式
```

### 输出模式2：HTML格式

```
适用场景：公众号（粘贴到秀米/135编辑器）、邮件、网页
输出内容：带内联样式的HTML代码
优势：精确控制颜色/字号/间距，所见即所得
注意：公众号编辑器只支持内联样式，不支持class
```

### 输出模式3：排版规则指南

```
适用场景：制定团队排版规范、教其他AI排版
输出内容：排版规则文档（标题规范/段落规范/配色/图片规范）
优势：一次制定，长期复用
```

## 排版执行流程

### Step 1：内容诊断

拿到原始内容后，先扫描：

```
□ 文章类型：干货教程 / 观点评论 / 故事叙事 / 产品介绍 / 新闻资讯
□ 内容长度：短文(<1000字) / 中文(1000-3000字) / 长文(3000+字)
□ 目标平台：公众号 / 小红书 / 知乎 / 通用
□ 内容调性：专业严肃 / 轻松活泼 / 温暖感性 / 年轻潮流
□ 是否有配图：有现成配图 / 需要配图建议 / 纯文字
```

### Step 2：结构重组

```
1. 提取/生成标题层级（H1-H3）
2. 划分段落（每段3-5行移动端）
3. 设定视觉断点（每800-1200字一个）
4. 标记强调元素（金句/加粗/引用）
5. 插入过渡句和节奏变化
```

### Step 3：视觉化处理

```
1. 应用标题前缀风格（根据调性选择A-E）
2. 应用配色方案（加载 references/color-and-style-library.md）
3. 设置强调样式（4级强调体系）
4. 添加分隔线/装饰元素
5. 规划图片位置（加载 references/image-layout-guide.md）
```

### Step 4：平台适配

```
1. 加载目标平台规范（references/platform-specs.md）
2. 调整字号/间距/图片尺寸
3. 适配平台特有元素（公众号原文链接/小红书标签等）
4. 按输出模式生成最终格式
```

### Step 5：排版自检

```
呼吸感检查：
□ 段落间有空行吗？
□ 有没有超过6行的长段落？
□ 板块之间有明确分隔吗？

节奏感检查：
□ 长短段落有交替吗？
□ 每800-1200字有视觉断点吗？
□ 开头三段能留住人吗？

层次感检查：
□ 标题层级清晰且不超过4级吗？
□ 强调不超过每段2处吗？
□ 金句框不超过3个吗？

平台适配检查：
□ 移动端显示正常吗（段落不超5行）？
□ 配色适合目标平台审美吗？
□ 图片尺寸符合平台要求吗？
```

## 排版禁忌（铁律）

1. **段落不超6行**——超过就拆，没有例外
2. **强调不泛滥**——每段加粗≤2处，全篇金句框≤3个
3. **标题不超4级**——H1-H4足够，H5以下说明结构有问题
4. **配色不超3色**——主色+辅色+点缀色，多了就乱
5. **首屏必须有料**——前3段决定读者走不走
6. **视觉断点不能断**——1200字以上必须有至少一个视觉元素
7. **移动端优先**——90%的人在手机上看，所有排版以移动端为准
8. **一致性至上**——全篇标题风格/配色/强调方式必须统一
