# 知乎/头条长文排版模板

> Markdown格式 | 深度长文 | 结构化排版 | 适合2000字以上

---

## 标准长文Markdown骨架

```markdown
# 文章大标题

> 一句话导语/核心观点（可选）

正文引言段落，用1-2段交代背景，引出全文主题。这一段决定读者是否继续往下看。

引言第二段，可以抛出一个问题、一个数据、或一个反直觉的观点，制造悬念。

---

## 01 第一章节标题

第一章节开篇段落，直接进入内容。

正文段落，每段控制在4-6行。涉及**核心概念**要加粗标注。

> 💡 金句或核心观点放在引用框中，全文不超过3个

### 小节标题（如需要）

小节内容，进一步展开论述。

- 要点一：具体说明
- 要点二：具体说明
- 要点三：具体说明

![配图描述](图片URL)
*▲ 图注文字*

---

## 02 第二章节标题

章节内容...

| 对比项 | 方案A | 方案B |
|--------|-------|-------|
| 维度一 | 内容  | 内容  |
| 维度二 | 内容  | 内容  |
| 维度三 | 内容  | 内容  |

---

## 03 第三章节标题

章节内容...

**步骤拆解：**

1. **第一步**：具体操作说明
2. **第二步**：具体操作说明
3. **第三步**：具体操作说明

---

## 写在最后

总结段落，回顾核心观点。

升华段落，从具体内容上升到更普遍的思考。

> 最后一句金句，适合被摘抄传播的那种。

---

*如果这篇文章对你有帮助，点个赞让更多人看到 👍*
```

## 头条特有排版技巧

```
头条编辑器与知乎不同，更接近公众号的富文本编辑器：

标题：使用编辑器的H2/H3按钮
加粗：选中文字点击B
引用：编辑器引用按钮
列表：编辑器列表按钮
图片：每300-500字插一张（头条算法喜欢多图）

头条特有习惯：
├── 标题22-30字，信息量要大
├── 首段直接给结论/悬念
├── 段落要短（3-4行）
├── 多用数字和数据
├── 图片用16:9横版
└── 结尾引导评论："你觉得呢？""欢迎留言讨论"
```

## 长文结构模板库

### 模板A：问题-分析-方案型（最常用）

```
引言：提出问题/现象
第一章：问题现状分析
第二章：原因深度拆解
第三章：解决方案
结语：总结+展望
```

### 模板B：论点-论据-结论型

```
引言：抛出核心论点
第一章：论据1（数据/案例）
第二章：论据2（理论/逻辑）
第三章：论据3（对比/反证）
结语：强化结论
```

### 模板C：故事-道理-行动型

```
引言：一个故事/案例
第一章：故事展开
第二章：从故事中提炼道理
第三章：具体怎么做（行动指南）
结语：回扣故事+升华
```

### 模板D：盘点-排名型

```
引言：为什么盘点这个话题
第一项：名称+分析
第二项：名称+分析
...
第N项：名称+分析
结语：总结推荐/排名
```
