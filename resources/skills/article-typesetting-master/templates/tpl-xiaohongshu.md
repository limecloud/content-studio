# 小红书排版模板

> 纯文本排版 | emoji驱动 | 短句节奏 | 1000字以内

---

## 标准笔记排版模板

```
🔥 标题文字控制在20字以内

正文第一句话开门见山，直接说最吸引人的点。
接一两句补充说明。

·

✅ 第一个要点
具体内容用1-2句话说清楚
可以补充一句细节

✅ 第二个要点
具体内容
补充细节

✅ 第三个要点
具体内容
补充细节

·

💡 总结或金句
用一句简短有力的话收尾
让人想截图保存的那种

┈┈┈┈┈┈┈┈┈┈┈┈┈┈

#标签1 #标签2 #标签3 #标签4 #标签5
#标签6 #标签7 #标签8 #标签9 #标签10
```

## 不同内容类型模板

### 干货教程型

```
📝 [数字]+[结果]型标题（如：5个技巧让你的XX提升3倍）

先说结论或者成果展示
让人知道看完能收获什么

·

1️⃣「技巧名称」
解释说明（1-2句）
实操要点

2️⃣「技巧名称」
解释说明
实操要点

3️⃣「技巧名称」
解释说明
实操要点

·

💡 总结一句话

记得收藏🔖下次用的时候不迷路～

#教程 #干货 #实用技巧
```

### 好物推荐型

```
✨ [产品名]用了[时间]真实感受

先说结论：推荐/不推荐/有条件推荐

·

📦「开箱」
第一印象描述

🧴「使用体验」
使用过程+真实感受
具体效果描述

💰「性价比」
价格+值不值
适合什么人买

·

⚠️ 注意事项/踩坑点
真实缺点也要说（更可信）

总结：一句话推荐语

#产品名 #测评 #好物推荐
```

### 经验分享型

```
💬 [身份]+[经历]+[结果]
如：从月薪5k到3w｜我做对了这3件事

背景介绍（2-3句）
让人知道你是谁、经历了什么

·

🔑 第一个关键决策/改变
具体怎么做的
效果怎么样

🔑 第二个关键决策/改变
具体怎么做的
效果怎么样

🔑 第三个关键决策/改变
具体怎么做的
效果怎么样

·

现在回头看，最重要的是______

你们有类似经历吗？评论区聊聊👇

#经验分享 #成长 #职场
```

## 小红书emoji使用规范

```
标题常用：🔥✨💡📝🎯💪🌟⭐
列表标记：✅❌▪️▫️1️⃣2️⃣3️⃣4️⃣5️⃣
强调提示：⚠️💡📌🔑❗💬
情感表达：🥰😭💕🙏👏🤝💯
引导互动：👇🔖📎➡️
装饰点缀：·  ┈  ꒰꒱  ˗ˏˋˎˊ˗

使用原则：
├── 每行最多1个emoji（多了就乱）
├── 小标题前统一用同一类emoji
├── 不要在正文句中插emoji（影响阅读）
└── 标签区不用emoji
```
