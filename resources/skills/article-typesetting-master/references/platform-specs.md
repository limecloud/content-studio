# 多平台排版规范速查

> 每个平台都有自己的"审美偏好" | 同一篇文章，不同平台要"换衣服"

---

## 微信公众号

### 基础参数

```
内容区宽度：实际渲染约 578px（手机端）
支持格式：HTML内联样式（不支持class/外联CSS）
图片宽度：建议 1080px 宽度上传，系统自动适配
封面图：大图 2.35:1（900×383px），小图 1:1（200×200px）
字数建议：1500-3000字（太短没价值感，太长完读率低）
```

### 排版规范

```
正文字号：15-16px（推荐15px）
正文颜色：#333333 或 #3f3f3f（不要纯黑#000）
正文行距：line-height: 1.8-2.0（推荐1.75em或2）
段间距：margin-bottom: 20-25px
字间距：letter-spacing: 0.5-1px（可选）

标题字号：
├── H1(文章标题)：系统自带，不在正文中设
├── H2(章节)：18-20px，加粗
├── H3(小节)：16-17px，加粗
└── 正文：15px

两侧留白：padding: 0 10-15px（编辑器通常自带）

特殊限制：
├── 不支持外部CSS class
├── 不支持JavaScript
├── 所有样式必须写内联 style=""
├── 不支持position定位
├── 表格支持有限（建议用图片替代复杂表格）
└── 代码块不原生支持（需用背景色+等宽字体模拟）
```

### 公众号排版最佳实践

```
1. 首段缩进可选（现在主流是不缩进、左对齐）
2. 段落之间用空行分隔，不要用首行缩进
3. 图片建议居中，宽度100%
4. 图片与上下文之间各留10-15px间距
5. 引用框用左边框+浅背景实现
6. 重点文字用颜色+加粗，不要用下划线
7. 文末建议加引导关注/点赞区
8. 图片加圆角 border-radius:8px 更精致
```

## 小红书

### 基础参数

```
内容格式：纯文本（不支持HTML/Markdown）
字数限制：正文最多1000字
标题限制：最多20字
图片数量：1-18张，首图最关键
图片比例：3:4竖版（1242×1660px）或 1:1
话题标签：10-15个，#号开头
```

### 排版规范

```
排版工具：纯文本 + emoji + 符号 + 换行

标题格式：emoji + 标题（≤20字）
正文段落：每段2-3行，用空行或emoji分隔
列表格式：emoji做列表符号（✅❌💡🔥✨📌）

换行规则：
├── 每句话一行（短句优先）
├── 段落之间空一行
├── 重点句子前后各空一行
└── 每3-4行插一个emoji装饰行

符号装饰库：
├── 分隔线：〰️〰️〰️ / ┈┈┈┈┈ / ·····
├── 列表符：▪️ ▫️ ◽ ◾ ● ○ ◇ ◆
├── 强调符：「」『』【】
├── 装饰符：꒰ ꒱ ˗ˏˋ ˎˊ˗ ᐢ..ᐢ
└── 箭头符：→ ➜ ➤ ▸ ▹

标签区格式：
正文结束后空一行
#标签1 #标签2 #标签3 ...（话题标签紧凑排列）
```

### 小红书排版模板

```
[emoji] 标题文字（≤20字）

正文第一段，开门见山。
空行制造呼吸感。

[emoji] 小标题1
内容内容内容
内容内容

[emoji] 小标题2
内容内容内容

┈┈┈┈┈┈┈┈┈

总结句或金句（制造截图传播）

#标签1 #标签2 #标签3 #标签4 #标签5
```

## 知乎

### 基础参数

```
支持格式：Markdown（部分语法）
字数建议：2000-5000字（知乎用户偏好深度长文）
图片要求：建议宽度1200px以上
支持元素：加粗/斜体/链接/引用/列表/代码块/分隔线/表格
```

### 排版规范

```
标题层级：H2和H3为主（H1是文章标题，系统渲染）
段落规范：每段4-6行（知乎PC端阅读多，可稍长）
引用块：用于金句/数据/他人观点（>语法）
加粗：核心概念和关键结论
列表：适合步骤、对比、总结
代码块：技术文章必备
分隔线：---（章节之间）

知乎特有习惯：
├── 开头常用"先说结论"/"直接上干货"
├── 长文开头可加目录（手动列表+锚点）
├── 引用要标注来源（知乎用户重视出处）
├── 技术文配代码，观点文配数据
└── 结尾常用"以上""希望对你有帮助"
```

## 头条/百家号

### 基础参数

```
支持格式：富文本编辑器（类似公众号）
字数建议：800-2000字（头条用户偏好中等长度）
图片要求：16:9 横版为主，至少3张
标题长度：建议22-30字（头条标题越长CTR越高）
```

### 排版规范

```
正文字号：16px（系统默认）
段落长度：每段3-4行（头条用户耐心较短）
图片频率：每300-500字配一张图
小标题频率：每500-800字一个

头条特有习惯：
├── 标题党文化（但不能过度）
├── 首段必须有信息增量（抓住算法推荐的初始流量）
├── 多用短段落（信息流中更易被读取）
├── 图片必须有（纯文字权重低）
└── 结尾引导评论（"你怎么看？"）
```

## 通用邮件/博客

### 排版规范

```
正文字号：14-16px
行距：1.6-1.8
正文颜色：#333333
链接颜色：#1a6baf（与正文有区分即可）
最大宽度：600-680px（邮件） / 750-900px（博客）
图片：宽度≤内容区宽度，带alt描述

邮件特有注意：
├── 必须用table布局（部分邮件客户端不支持div）
├── 所有样式写内联
├── 图片不要作为唯一信息载体（可能被屏蔽）
├── 背景色用浅色（深色在邮件中显示异常概率高）
└── 总宽度≤600px
```
