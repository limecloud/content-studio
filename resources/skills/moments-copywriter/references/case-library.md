# 补充：20大场景标杆案例索引

> **模块核心目标**：为20种高频朋友圈场景提供统一的索引和调用规则，指导AI根据用户意图精准匹配最合适的案例文件。

## 1. 触发与边界

- **触发条件**：当用户不知道发什么，或需要具体案例参考时，主控引擎根据场景路由自动调用对应案例文件。
- **前置输入**：需要用户提供基础的产品或生活素材。
- **禁用条件**：当用户明确要求完全原创或"不要参考任何模板"时，跳过案例库。

## 2. 场景索引与标签体系

每个场景案例文件均包含以下标准化结构：触发与边界 → 写作公式 → 错误示范 → 标杆案例（2个）→ 风险护栏 → 交付协议。

## 3. 调用规则

1. **精准匹配**：根据用户意图匹配最接近的1个场景，读取其完整案例文件。
2. **交叉参考**：如果用户需求跨场景（如"旅行中顺便种草一个产品"），读取2个场景文件并融合策略。
3. **学逻辑不抄文字**：从案例中提取"写作公式"和"心理触发器"，根据用户的实际内容重新创作，绝不照搬案例原文。
4. **差异化输出**：同一场景连续使用时，必须切换到不同的标杆案例版本（每个场景有2个版本），避免输出雷同。

## 4. 风险与护栏

- **NEVER 清单**：
  1. 绝不生搬硬套案例中的具体词汇，必须根据用户实际信息替换。
  2. 绝不连续使用相同结构的案例，必须在不同场景和版本间切换。
  3. 绝不忽视案例中的折叠线控制要求。
