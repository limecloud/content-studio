# UI 评审门禁

实现前确认：

- 页面是否有一个明确业务对象。
- 用户当前缺什么输入。
- 主动作只有一个。
- 完成后交付物去哪里。
- 异常状态能否恢复。
- 所有状态是否来自真实 store/logs/artifacts。

实现后检查：

- 是否仍沿用当前一级导航。
- 是否有不可追溯 mock、占位图或伪成功。
- 是否卡片套卡片。
- 文本是否溢出按钮、卡片、chip。
- 低宽度下网格是否坍塌为可读单列。
- 深色模式是否至少保持可读。
- 截图是否确实查看过，不只看命令输出。

必须重做的信号：

- 页面像功能入口合集。
- 主区没有可判断内容。
- 右侧抽屉承载了主路径，导致中间对象失焦。
- 复制外部产品的信息架构，破坏内容工厂导航。
