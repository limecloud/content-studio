# 内容工厂工作台布局参考

## 截图抽象

从用户提供的 AI 营销截图中学习这些结构：

- 左侧窄应用栏：图标为主，承载模块切换和设置状态。
- 左侧任务参数栏：上传素材、选择素材、参数、模型、Prompt、主按钮。
- 中间主任务区：顶部能力带、筛选条、案例/结果网格。
- 右侧浮动抽屉：历史记录或提示词助手，默认不抢占主任务区。
- 卡片内容直接呈现输入/输出对比、评分、标签、预览、尝试示例。

不要照搬这些内容：

- 外部产品品牌名、一级导航、账号体系。
- 与内容工厂无关的能力入口。
- 不可追溯的示例素材和假生成状态。

## 标准栅格

优先使用：

```text
module-shell
├── task-rail: 300-360px
├── content-board: minmax(0, 1fr)
└── evidence-drawer: 300-380px，可折叠
```

卡片网格建议：

- 案例/素材：`repeat(auto-fill, minmax(240px, 1fr))`
- 特征/脚本：`repeat(auto-fill, minmax(260px, 1fr))`
- 历史列表：左 320-380px，右详情 `minmax(0, 1fr)`

## 组件密度

- 顶部能力按钮：图标 + 4-8 字短标题，最小高度 72-88px。
- 参数分组：标题 13-15px，说明 11-12px。
- 主按钮：模块内只保留一个当前主动作。
- 卡片圆角不超过 8px，优先边框和浅底。
- 面板内不要再套大卡片；使用分隔线、标签、紧凑列表。

## 状态表达

- `empty`：说明当前缺什么输入，以及下一步主动作。
- `blocked`：说明缺哪个模型/Key/事实源，并给恢复入口。
- `running`：显示正在处理的对象和阶段，避免只转圈。
- `succeeded`：显示产物、评分、来源和下一步交付去向。
- `failed`：保留错误和运行追溯入口。
