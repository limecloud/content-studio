## 实现口径

这个原型只作为业务路径和信息结构参考，不是逐页照搬清单。真实客户端优先遵守 PRD、验收计划和业务 UI 契约：

- 不新增另一套一级导航。
- 不把 prototype 里的每个页签都拆成独立页面，能合并到现有知识地图、审核任务和品牌战情室工作台的，优先合并。
- 不保留功能罗列式、装饰性或需要理解工程术语的设计。
- 每次落地必须对应一个真实业务对象、主动作、异常恢复路径和下游交付物。

当前已从 prototype 反向落地到真实客户端的能力：

- 团队知识包详情浏览已合并到内容知识地图右侧交付区，展示版本、文件、对象 key、sha256、确认状态和最近版本。
- 离线变更包导出 / 导入已接入内容知识地图工作台，导出包不包含本机 `workspacePath`、密钥、凭证或本机绝对路径。
- 评论痛点的用户原声已落到真实矩阵证据列，优先展示用户原话或客服记录，而不是只显示证据 ID。
- 审核任务已把 prototype 中“来源证据、风险判断、处理方式”的详情合并进真实审核台：可展开证据原文 / 摘录、证据来源类型、证据状态、来源引用和推荐恢复路径。
- 品牌战情室已把 prototype 中“目标树”的业务层合并进真实工作台：可查看目标类型、优先级、渠道、成功标准、关联信号、资源包和队列动作，补齐信号到资源包和执行队列之间的决策层。
- 品牌战情室已把 prototype 中“作战编组 / 执行队列 / 行动记录”的详情合并进真实工作台：资源包可展开真实卖点、场景、证据摘录、禁用边界、资源缺口、素材和交接引用；队列可查看动作、交付去向、席位、渠道、发布检查和恢复路径；行动记录可追溯操作者角色、产物引用、回写、未通过原因和团队同步。
- 真实客户端作战分组已补左侧 5 个直达入口：品牌战情室、目标树、作战编组、执行队列和行动记录不再只是原型页签，每个入口都有独立页面标题、当前业务对象、主判断、主动作、交付去向和真实数据图表；没有真实战情室记录时只显示恢复路径，不填充 mock 内容。

本次原型改进重点：

- 左侧所有可见导航都可切换，不再保留不可点击的 Prompt / SOP / 素材库入口。
- 右侧新增“当前选中对象”和“本次交付结果”面板；点击表格行、资源卡、队列卡、知识包目录或素材卡，会切换到该对象的证据、风险、恢复路径和交付去向。
- 按钮不再只弹静态反馈；生成、送审、补证据、补素材、回写、发布和导出动作会更新交付结果与行动记录。
- Prompt 交接、SOP 输入和素材库页补齐真实业务内容，展示从已审核资源包到下游模块的交接方式。
- 筛选、页签和知识包目录可交互，用于确认“普通用户不懂 Ontology 也能看懂正在处理什么、缺什么、下一步做什么”。

- 角色：电商运营、新媒体运营、品牌负责人、审核人员、内容负责人、内容工程师。

- 主路径：输入源 -> 生成流程 -> 评论痛点 / 卖点矩阵 / 场景矩阵 / IP 口径 / 竞品观察 -> 审核任务 -> 团队知识包 -> 品牌战情室 -> 作战编组 -> 执行队列 -> 素材回写 -> 行动记录 -> 高级导出。
- 验收标准：普通用户不看到 `Ontology` 工程术语；每条卖点和主张有证据状态；每个评论痛点保留用户原声；矩阵能标出缺证据、缺素材、待审核和可发布；审核通过后可生成 PromptDraft；IP 内容引用同一口径版本；品牌战情室能从评论、竞品、素材表现和品牌风险生成作战目标；作战编组能组合目标、资源包、负责人、渠道和发布检查；执行队列能区分可执行、待审核、待补资源和已拦截动作；素材表现只作为排序和复盘信号；团队知识包可作为下游默认知识源；行动记录可追溯资源、产物和发布检查结果；高级导出通过包结构和安全校验。

## 原型契约

目标用户：电商运营、新媒体运营、品牌负责人、审核人员、内容负责人。

用户目标：

- 把产品 brief、SKU、评论和素材整理成可复用的内容知识地图。
- 在不理解 Ontology 的情况下完成卖点拆解、场景穷举、审核、发布和团队共享。
- 团队共用一套已审核口径，避免每个人临时问模型得到不同结果。
- 把评论、竞品、热点、素材表现和品牌风险转成可指挥的品牌内容作战闭环。

主页面骨架：固定左侧导航、顶部项目上下文、中间主任务区、右侧来源 / 审核 / 团队状态栏。

原型必须遵守以下门禁：

- 不能把页面做成功能入口合集。
- 每个页面必须展示一个正在处理的业务对象。
- 每个页面只能有一个当前主动作。
- 每个异常状态必须有恢复路径。
- 完成后必须能交付到 Prompt 工作台、场景库、SOP、素材库、团队知识包、行动记录或高级导出。

统一词表：

- 内容知识地图、卖点矩阵、场景矩阵、素材覆盖表、审核任务、提示词依据、团队知识包、品牌战情室、作战编组、执行队列、行动记录、发布检查、补证据。

禁用词表：

- `Ontology`
- `Concept`
- `Relation`
- `CoverageMatrix`
- `PromptGroundingContext`
- `DecisionGate`
- `ActionLog`
- `DraftChange`

异常边界：

- 没有输入源时可以创建空项目，但不能生成事实主张。
- 缺证据主张不能进入可发布 Prompt。
- 团队同步冲突不能静默覆盖。
- 模型未配置时显示待配置状态，不伪造结果。
- 作战系统不能自动发布、刷量、伪造互动或绕过平台规则。
- 信号、投放表现和素材表现只能触发行动和复盘，不能自动变成产品事实。

## 当前帧内容

原型已补齐以下可点击页面：

- 内容知识地图：输入源处理台、核心维度、流程导轨、缺口清单。
- 生成流程：五步生成流程、质量问题清单、构建模式、模型未配置兜底和可恢复路径。
- 评论痛点：812 条评论聚类、18 个痛点、42 条用户原声、待补资料和选题输出。
- 卖点矩阵：筛选、指标、矩阵表、组合详情、证据、禁用边界、批量动作。
- 场景矩阵：变量选择器、场景矩阵、推荐场景卡、素材缺口、生成预览。
- IP 口径：身份、观点、语言规则、方法论、禁区、平台内容矩阵和漂移检查。
- 竞品观察：公开竞品内容的结构提取、证据形式、差异机会和不可搬运边界。
- 审核任务：审核队列、待审详情、来源证据、风险判断、处理方式。
- 团队知识包详情浏览器：以 `BreezeGo Air 便携风扇 v1.4` 为真实样例，展示包概览、产品事实、卖点与证据、品牌口径、场景卡、FAQ、素材覆盖、提示词依据和高级包文件。
- Prompt 交接：展示轻量通勤图文 Prompt 的输入对象、可用证据、素材缺口、禁用边界、提示词依据预览和交付结果。
- SOP 输入：展示续航异议解释资源包如何进入 FAQ、详情页模块、直播答疑和私域话术流程，并保留人工确认项。
- 素材库：展示素材覆盖关系视图，从素材反查卖点、痛点、场景、作战目标、缺口和回写边界。
- 品牌战情室：信号雷达、目标树、今日战役、资源状态和风险摘要。
- 作战编组：信号 -> 目标 -> 资源包 -> 发布检查 -> 标准动作的编组视图。
- 执行队列：可执行、待审核、待补资源和已拦截动作的队列视图。
- 素材回写：素材覆盖、表现标签、回写明细、缺口任务和“表现不替代事实”的边界。
- 行动记录：时间线、产物、素材覆盖回写和高表现组合复盘。
- 高级导出：团队知识包、互操作文件、发布包校验、来源校验和安全校验。

右侧栏会随页面切换上下文，分别展示来源证据、发布检查、生成流程状态、评论痛点摘要、卖点组合详情、场景摘要、IP 口径检查、竞品边界、审核辅助、版本发布检查、战情室摘要、作战资源包、队列处理规则、素材回写边界、复盘摘要和导出校验。

- 当前项目、分步生成运行、评论痛点、卖点组合、场景组合、IP 口径、竞品观察、审核任务、团队知识包、内容信号、作战单元、执行队列动作、素材回写、行动记录、Prompt 交接、SOP 输入、素材库和高级导出。
