# 内容知识地图 v1 业务 UI 契约

更新时间：2026-06-01
状态：Local Verified / Production Evidence Pending
依据：`docs/aiprompts/business-ux-contract.md`、`.codex/skills/bugu-product-design-cheatsheet/SKILL.md`

## 1. 设计结论

v1 普通用户界面不是功能入口合集，也不是“本体论编辑器”。它必须表现一个真实业务对象正在被处理：

```text
输入资料
-> 当前业务对象
-> 缺口 / 风险 / 审核状态
-> 唯一主动作
-> 交付到下游
-> 复盘回写
```

任何新增页面、原型和普通用户 UI 代码，必须先满足本文契约。无法映射到用户故事、用户用例、当前对象状态或交付物的控件默认不加。

## 3. 页面级业务契约

| 内容知识地图 | 内容工程师 / 运营 | 一个品牌、产品、IP 或活动项目 | 待补资料 / 待生成 / 待审核 / 可交接 | 生成知识地图 | 卖点矩阵、场景矩阵、审核任务。 |

| 评论痛点 | 新媒体运营 | 一批评论、差评或客服问题 | 已聚类 / 缺原声 / 待命名 / 可输出选题 | 确认痛点 | 痛点矩阵、选题方向、补证据任务。 |

| 场景矩阵 | 新媒体运营 / 短视频运营 | 一个场景组合 | 缺素材 / 待审核 / 可生成提示词 | 生成提示词依据 | 场景卡、图片 Prompt、视频 Prompt。 |

## 4. 页面组织规则

### 4.1 中间主任务区

中间区域必须先显示当前业务对象，而不是先显示模块能力：

- 当前项目、产品、信号、目标、资源包或待审主张。
- 当前对象的证据、缺口、审核状态、素材状态和风险。
- 用户需要做的判断：确认、送审、补证据、生成依据、交接、回写或发布。

### 4.2 右侧来源 / 审核 / 恢复栏

右侧栏不做装饰信息，应承接当前对象的恢复路径：

- 来源引用：产品资料、评论原声、品牌文档、IP 版本、素材记录。
- 发布检查：证据、品牌口径、平台规则、竞品边界、素材可用、权限。
- 异常恢复：去补资料、去配置生成服务、发起审核、改写表达、创建补素材任务。
- 交付去向：Prompt 工作台、场景库、SOP、素材库、团队知识包或导出包。

### 4.3 主动作约束

每页只允许一个当前主动作：

| 页面类型 | 主动作示例 | 辅助动作 |
| --- | --- | --- |
| 构建页 | 生成知识地图 / 继续生成 | 查看来源、补资料、打开问题清单。 |
| 矩阵页 | 送审当前组合 / 生成提示词依据 | 筛选、排序、分页、选择本批、查看证据、标记缺素材。 |
| 审核页 | 提交审核结论 | 改写建议、补证据、查看来源。 |
| 作战页 | 创建作战目标 / 生成执行队列 | 调整优先级、补资源、查看风险。 |
| 队列页 | 执行当前动作 | 打开拦截原因、发起审核、创建补资源任务。 |
| 团队页 | 发布团队知识包 | 生成变更包、提交同步、查看冲突。 |

## 5. 异常和待配置契约

| 异常 | 用户可见状态 | 恢复路径 |
| --- | --- | --- |
| 没有输入资料 | 待补资料 | 登记产品资料、SKU、评论、IP 素材、竞品观察或历史素材。 |
| 模型未配置 | 模型待配置 | 打开平台模型设置；不生成伪结果。 |
| 主张无证据 | 缺证据 | 创建补证据任务或改成弱表达。 |
| 包含禁用表达 | 发布检查未通过 | 改写表达或标记禁用。 |
| 素材不足 | 缺素材 | 创建补拍、补图、补视频或素材导入任务。 |
| 包含仅本机资料 | 不能同步或发布 | 回到输入源处理共享范围；处理前不能生成变更包或团队知识包。 |
| 团队同步冲突 | 有冲突待处理 | 查看影响内容、版本差异和处理建议，请求审核人员确认。 |
| Bugu 服务不可用 / 未登录 | 未同步到团队 | 保留本机草稿和变更包，恢复连接后重新提交，不伪造团队发布成功。 |
| 服务端不可用 | 待同步 | 保存离线草稿，恢复后重新提交。 |
| 未生成本机预览 | 暂无包内容 | 先生成本机预览，再切换查看 KNOWLEDGE、提示词依据、素材覆盖、答疑和互操作文件。 |

底层状态可以继续使用 `blocked`、`local-only`、`conflict` 等工程值，但普通用户文案必须转换为业务状态。

## 6. 反功能平铺门禁

出现以下任一情况，原型和 UI 代码不得进入实现：

- 页面第一屏主要是功能入口、能力说明、状态卡片或按钮矩阵。
- 页面看不出当前正在处理哪个项目、信号、目标、资源包、素材或审核任务。
- 多个按钮同等权重，用户不知道下一步点哪个。
- 状态只显示“完成 / 可用 / 待处理”，没有证据、风险、缺口或恢复路径。
- 点击完成后不知道交付到 Prompt 工作台、场景库、SOP、素材库、团队知识包还是导出包。
- 普通用户必须理解 Ontology、Concept、CoverageMatrix、PromptGroundingContext、DecisionGate、ActionLog 等词才能继续。

## 8. 工程验收

- UI 文案扫描不能在普通用户模块中命中禁用工程词。
- `ContentKnowledgeMapModule`、`ContentReviewTasksModule`、`BrandCommandCenterModule` 必须只消费 View Model 和业务记录，不写矩阵构建、审核迁移或发布检查算法。
- 作战分组的品牌战情室、目标树、作战编组、执行队列和行动记录入口必须投影真实 `BrandCommandCenterRecord`、内容知识地图、执行队列和行动记录；空态只能提示恢复路径，不能用 mock 数据填充页面。
- IPC 只暴露粗粒度业务动作，不能把本地 JSON 结构或服务端 URL 泄漏到 renderer。
- Bugu 团队事实源未接入时，团队动作只能显示“未同步到团队”或“本机预览”，不能显示已发布。
- 高级导出页的包文件列表必须跟随当前可读取的本机预览包；普通用户点击文件时读取真实包内容，不能用固定文案或 mock 详情替代。
- HTML 原型 README 必须引用本契约，并说明每个页面的业务对象、主动作、异常恢复和交付物。
