## UI 复刻规则

1. 图片页使用桌面工作台比例：左侧素材输入栏，中间模板配置和预览画布，右侧沿用全局参数栏。
2. 模板切换必须改变参数表单，不能所有模板共用同一组字段。
3. 技能编辑弹窗必须展示当前技能完整 JSON，包含 `prompts.system`，保存后影响本次会话。
4. 技能编辑弹窗需要提供独立的「系统提示词」视图，方便查看和修改 `prompts.system / enhance / negative`。
5. 多选参数需要保留上一代的 `全选` 入口和勾选态反馈，详情页分区图尤其要可一键选中 16 个分区。
6. 生成结果卡必须提供「详情」入口，能查看结果图、文件名、模型、提示词、模板、比例、分辨率、数量和日志编号。
7. 图片生成日志必须提供「详情」和「复用参数」入口，方便从历史请求回填提示词、模式、模板和参数。
8. 页面主题继续使用 布谷AI 当前 light / emerald 体系，不复刻上一代暗色主题。
9. 不出现上一代品牌露出；文档中只称“上一代产品”或“legacy yanshi”。
