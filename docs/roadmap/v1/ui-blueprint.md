# 布谷AI内容工厂 v1 UI 蓝图

更新时间：2026-05-19
状态：Draft
参考截图：Image #1 - Image #5；上一代 Web 调研见 `docs/roadmap/v1/yanshi-legacy-research.md`

## 1. 成套原型契约

目标用户：电商运营、新媒体运营、内容策划、短视频剪辑、设计助理、品牌 / 商品负责人。

用户目标：在一个桌面工作台中使用已成型知识库完成文章生成、产品图片生成、爆款视频拆解、复刻脚本生成和视频素材生成队列。

主页面骨架：

```text
Windows / macOS 桌面窗口
┌────────────────────────────────────────────────────────────────────┐
│ 左侧能力导航 │ 中间工作区                                         │ 右侧全局参数 │
│ 图片 / 视频 / 文案 / 知识 │ 输入 / 模式 / 预览 / 日志 / 内容流      │ 模型 / 引用   │
└────────────────────────────────────────────────────────────────────┘
```

统一词表：

- 产品名称：布谷AI内容工厂
- 图片主链：图片生成
- 视频主链：视频生成
- 视频复刻链：爆款拆解
- 文案主链：文章生成
- 知识主链：已成型知识库
- 资产主链：素材库 / 生成历史
- 模板：预设提示词
- 能力 对用户表达：提示词模板 / 拆解维度 / 生成方式
- 能力管理：高级能力库 / 可视化 能力 面板
- 主按钮：启动渲染引擎 / 开始拆解 / 生成脚本 / 生成视频 / 生成大纲 / 生成正文 / 导入知识库
- 结果区：预览图 / 生成日志 / 片段拆解结果 / 文章正文 / 知识引用 / 生成视频历史

禁用词表：默认生成 UI 不直接出现 `运行底座`、`生成服务适配`、`Claude SDK`、`能力路径`、`IPC`、`payload`。这些只出现在设置高级信息、能力管理详情或开发者日志。

视觉锚点：深色半透明桌面工作台、霓虹粉 / 青 / 紫强调色、圆角卡片、内发光、分隔线、右侧参数舱。

状态模型：

- 空态：等待上传 / 等待生成
- 可编辑：已选择模式，可输入提示词
- 生成中：按钮 loading、结果区占位
- 成功：预览图网格 / 脚本结果 / 历史记录
- 失败：红色问题态、展示错误和重试
- 禁用：批量 / 定时 / 未接入模块变暗


### 1.1 上一代 Web 调研摘要

2026-05-19 使用 Playwright 调研上一代 Web 产品后，确认图片页的可复用 UI 模式：

- 顶层是「图片 / 视频 / AI」Tab；布谷AI内容工厂保留更完整的左侧能力导航，但图片页要继承这一代的低学习成本。
- 图片页保留产品图 `0/10`、参考图 `0/6`、提示词、模式按钮、模板按钮、右侧参数和预览大盘。
- 9 个图片模板不是普通 chip，而是参数化 能力 表单；选择模板后必须出现字段卡片。
- 批量模式显示任务统计、多线程和文件夹入口；v1 只做壳和状态，不做假并发。
- AI 页显示快捷指令和本地 助手 端口；v1 保留入口说明，不打断图片 / 文章 / 视频主链。

## 2. 全局布局

### 2.1 左侧栏

尺寸建议：宽 330-360px，固定左侧。

模块：

1. 顶部品牌区
   - Logo / 名称：`布谷AI内容工厂` 或后续品牌名
   - 图标按钮：文档 / 设置
2. 一级 Tab
   - 图片
   - 视频
   - 文案
   - 知识库
   - 资产
3. 能力列表
   - 当前选中项使用高亮渐变底和左侧色条
   - 禁用项降低透明度
4. 管理入口
   - 模型配置
   - 能力管理
5. 处理模式
   - 单次处理：v1 可用
   - 批量处理：v1 disabled
   - 定时任务：v1 disabled
6. 主题色
   - 允许保留截图底部主题切换，但 v1 可先静态展示

### 2.2 中间工作区

中间区是主要操作面，随图片 / 视频 / 文案 / 知识库 / 资产切换。

图片页：

```text
顶部生成模式栏
知识引用 / 品牌提示词包 / 场景卡
上传区：产品图 / 参考图
提示词输入区
启动按钮
预览 / 日志区
```

视频页：

```text
页头：视频复刻引擎 + 设置提示词
步骤栏：视频拆解 / 脚本生成 / 视频生成
步骤内容区：视频拆解、脚本、图片素材、视频提示词和生成队列
```

文章页：

```text
页头：文章生成 + 选择知识库引用
步骤栏：选题 / 大纲 / 正文 / 发布检查 / 导出
步骤内容区：左侧输入，右侧正文预览和检查结果
```

知识库页：

```text
页头：知识库 + 选择内置知识库 / 导入成型文件 / 搜索
列表区：知识库卡片、类型、标签、更新时间
详情区：摘要、原文、引用片段、被使用记录
```

资产页：

```text
页头：素材库 / 生成历史
筛选区：文章 / 图片 / 脚本 / 视频队列
详情区：输入、输出、模型、知识引用、导出操作
```

### 2.3 右侧全局参数

尺寸建议：宽 380-420px，固定右侧。

字段顺序固定：

1. 文字模型
2. 图片模型
3. 视频模型
4. 知识库引用开关
5. 生成数量
6. 图片比例
7. 分辨率
8. 图片质量
9. 文章长度 / 平台 / 语气等模块参数

交互：

- 单选 chip 用霓虹高亮。
- Slider 展示当前数值。
- 模型字段为只读显示 + 点击进入模型配置。

## 3. 页面蓝图

### 3.1 图片生成页（对应 Image #1）

目标：让用户完成电商图片生成的单次流程。

保留元素：

- 顶部打标 / 不打标切换。
- 产品图上传卡片，计数 `0/10`。
- 参考图上传卡片，计数 `0/6`。
- 提示词输入区，初始为空；上传素材后出现轻量 `@` 引用入口，输入 `@` 时弹出可选图片列表。
- 渐变主按钮 `启动渲染引擎`。
- 中间模式选择区。
- 右下预览图网格。
- 右侧全局参数。

生成模式：

- 自由模式
- 选择预设提示词
- 智能生成
- 固定生成
- 电商白底主图
- 海报图
- 场景图
- 详情页分区图
- 买家秀图
- 3D 立体图
- 爆款拆解生成
- 影视级画面
- 美食摄影

模板参数卡：

- 位于模板 chip 下方，避免详情页弹窗化；列表页和主操作区保持常驻，详情配置用卡片或弹窗。
- 卡片展示模板 icon、名称、版本、分类、描述和字段。
- 文本字段使用单行输入；长卖点 / 主体描述使用 textarea；单选 / 多选使用 chip。
- 必填字段只做提示，不阻塞纯提示词生成；生成请求必须携带已填 `templateInputs`。
- 详情页分区图的分区类型支持多选，海报图保留文案、价格、行动按钮和版式参数。

模板编辑弹窗：

- 顶部技能操作区保留 `AI 创建`、`导入`、`导出 / 编辑`。
- `导出 / 编辑` 打开 JSON 编辑弹窗，包含 `直接编辑` 和 `AI 辅助修改`。
- 直接编辑保存后更新当前会话模板表单；AI 辅助修改在本地 内容助手接入前 disabled。

v1 UI 状态：

| 状态 | 表现 |
| --- | --- |
| 初始 | 上传区为空，预览区展示示例图或空态。 |
| 有素材 | 上传卡计数更新，提示词区可编辑，并可通过 `@文件名` 点名重点参考图。 |
| 生成中 | 主按钮 loading，预览区展示骨架屏。 |
| 成功 | 预览图网格出现，导出按钮可用。 |
| 失败 | 预览区展示错误卡片和重试按钮。 |

### 3.2 模型配置弹窗（对应 Image #2）

目标：统一配置 API 与模型，避免每个模块重复设置。

布局：

- 弹窗宽约 980-1040px。
- 顶部标题：模型配置。
- 右上关闭按钮。
- 底部操作：取消 / 保存。
- 内容区分四块：API 连接、文字模型、图片模型、视频模型。

字段：

| 分组 | 字段 |
| --- | --- |
| API 连接 | API 端点（统一）、API Key（统一） |
| 文字模型 | 模型输入、获取模型按钮 |
| 图片模型 | 支持多个模型，以逗号分隔或多选 chip |
| 视频模型 | 模型输入、获取模型按钮 |

保存规则：

- API Key 不回显明文。
- 保存后刷新右侧全局参数。
- 获取模型失败时展示内联错误，不关闭弹窗。

### 3.3 视频拆解页（对应 Image #3）

目标：把一个高价值视频拆成可复用结构。

结构：

```text
左侧：原视频导入
右侧：片段拆解结果 / 分析维度选择
底部：拆解摘要卡片
```

导入方式：

- 上传本地视频，支持 MP4 / MOV / WEBM。
- 粘贴视频链接，点击下载。
- 抽帧间隔：智能拆解 / 固定间隔。

拆解维度卡片：

- 16 个卡片默认全选。
- 支持全选 / 清空。
- 每个卡片展示名称、简短说明和选中点。

输出：

- 片段列表。
- 每个片段的钩子、卖点、节奏、画面和转化设计摘要。

### 3.4 脚本生成页（对应 Image #4）

目标：把拆解结果迁移到新产品，生成复刻脚本。

左栏：新产品信息

- 产品名称
- 场景背景
- 字幕选择
- 视频语音
- 自定义需求
- 上传产品图
- 参考产品图背景 checkbox

右栏：新视频脚本

- 比例：默认 9:16
- 镜头：自动
- 时间：默认 15 秒
- 新视频脚本内容
- 分镜图等待生成

脚本结构：

```text
镜头 1：开头钩子
镜头 2：痛点 / 场景
镜头 3：产品卖点
镜头 4：证明 / 对比
镜头 5：行动引导
```

### 3.5 视频生成页（对应 Image #5）

目标：根据脚本、分镜和素材进入生成队列。

字段：

- 视频模型
- 视频比例
- 视频时长
- 上传图片
- 上传视频
- 视频提示词

结果：

- 生成视频历史
- 参考素材区
- 当前视频任务状态

v1 可先实现：

- 素材上传 UI
- 视频提示词编辑
- 生成任务队列占位
- 历史记录结构

真实视频生成可在 生成服务 接入后启用。

### 3.6 文章生成页

目标：基于知识库、产品素材和文章 能力 生成可发布的长文或营销文案。

结构：

```text
左侧：文章输入 / 知识引用 / 素材引用
右侧：标题候选 / 大纲 / 正文 / 发布检查
底部：生成历史与导出操作
```

字段：

- 文章类型：公众号长文 / 小红书笔记 / 商品种草文 / 详情页文案 / 短视频口播稿。
- 平台：公众号 / 小红书 / 抖音 / 电商详情页 / 自定义。
- 目标读者：人群、痛点、购买阶段。
- 主题或商品：产品名称、核心卖点、场景。
- 知识引用：可多选知识条目和片段。
- 语气：专业 / 亲切 / 犀利 / 种草 / 品牌统一。
- 字数范围：短文 / 中篇 / 长文 / 自定义。

输出：

- 标题候选 5-10 个。
- 文章大纲。
- Markdown 正文预览。
- 发布检查：事实一致性、禁用表达、平台适配、CTA、素材建议。

### 3.7 品牌提示词包与产品场景库

目标：承接案例文档中的「基于知识库生成产品场景库，再基于场景库做文案、脚本和素材」。

结构：

```text
左侧：知识库引用 / 已选章节
中栏：品牌提示词包
右栏：产品场景库
底部：发送到文章 / 图片 / 视频
```

品牌提示词包：

- 品牌口吻
- 视觉风格
- 卖点表达
- 合规边界
- 平台限制
- 图片提示词片段
- 视频提示词片段

产品场景卡：

- 目标人群
- 痛点场景
- 使用场景
- 画面构图
- 主卖点
- 口播方向
- 图片素材建议
- 视频素材建议

流程表现：

```text
知识库引用 -> 生成提示词包 -> 生成场景卡 -> 生成图片素材 -> 生成视频素材
```

说明：图片素材是视频生成的重要输入，但视频页仍允许叠加脚本、参考视频拆解和外部素材。

### 3.8 知识库页

目标：把已经整理好的产品型知识库和个人 IP 型知识库接入成本地可引用事实源。

结构：

```text
顶部：选择内置知识库 / 导入成型文件 / 搜索
左栏：知识库列表 + 产品型 / 个人 IP 型 / 标签筛选
中栏：知识库章节和摘要
右栏：引用片段 / 使用记录 / 发送到生成
```

资料类型：

- 产品型知识库：科学基础、品牌定位、产品矩阵、卖点体系、场景话术、异议处理、合规红线、Q&A、规格资料
- 个人 IP 型知识库：人物档案、定位、时间线、故事素材、方法论、价值观、金句库、写作风格、禁忌边界

v1 状态：

| 状态 | 表现 |
| --- | --- |
| 空态 | 提示选择内置产品 / 个人 IP 知识库，或导入已成型 DOCX / Markdown / 文本 / JSON。 |
| 有资料 | 展示知识库卡片、类型、章节结构、标签、更新时间和摘要。 |
| 检索中 | 保留旧列表并展示搜索 loading。 |
| 无结果 | 提示换关键词或清空筛选。 |
| 引用中 | 选中片段显示高亮，并可发送到文章 / 图片 / 视频。 |

### 3.9 素材库与生成历史页

目标：让文章、图片、脚本和视频队列结果可回看、复用和导出。

列表字段：

- 类型：文章 / 图片 / 视频脚本 / 视频队列。
- 标题或摘要。
- 创建时间。
- 使用模型。
- 使用 能力。
- 知识引用数量。
- 状态：成功 / 失败 / 已取消 / 等待中。

操作：

- 查看详情。
- 复制提示词或正文。
- 导出 Markdown。
- 打开本地素材。
- 重新使用本次参数。

### 3.10 能力管理页

目标：让内容团队知道当前有哪些内容能力可用，并能把内置 能力 安装到当前工作区。

布局：

```text
顶部：能力管理 + 扫描刷新 + 当前工作区
左栏：来源筛选 / 状态筛选
中栏：能力 卡片列表
右栏：能力 详情 / 安装 / 启用状态 / 校验错误
```

列表字段：

- 能力名称
- 描述
- 来源：内置 / 项目 / 用户 / 兼容
- 状态：有效 / 无效 / 已安装 / 已启用
- 适用链路：图片提示词 / 视频拆解 / 脚本生成 / 合规检查

操作：

- 扫描刷新
- 安装内置 能力到工作区
- 启用 / 停用当前 能力
- 复制本地路径
- 查看 `globs`、`alwaysAllow`、`requiredSources`

状态规则：

| 状态 | 表现 |
| --- | --- |
| 无 工作区 | 安装按钮禁用，提示先选择 工作区。 |
| 内置未安装 | 显示「安装到项目」。 |
| 项目已安装 | 显示「已安装」和启用开关。 |
| 无效 能力 | 显示红色错误卡，不允许启用。 |
| 扫描中 | 列表骨架屏，不清空旧结果。 |

## 3.11 批量与 AI 入口边界

批量模式：

```text
任务统计：总数 / 已完成 / 未完成 / 等待区 / 失败数量
线程选择：1-7 线程 / 智能
上传方式：点击选择文件夹
状态：v1 Shell，不能生成成功日志
```

内容助手入口：

```text
快捷指令：/skill /model /help
连接状态：展示本地 内容助手服务是否可用
操作：重试连接 / 独立窗口打开
状态：v1 后续接入，不能替代图片生成主按钮
```

## 4. 视觉规范

颜色建议：

```text
背景：#050411 / #070817
卡片：rgba(18, 18, 32, 0.78)
边框：rgba(255, 255, 255, 0.10)
粉色强调：#ef3fa3
青色强调：#00d7e8
紫色强调：#8b5cf6
文字主色：#f4f0ff
文字次色：#89849a
警告：#f59e0b
错误：#f43f5e
成功：#22c55e
```

组件风格：

- 卡片圆角 18-28px。
- 大按钮可使用粉 -> 紫 -> 青渐变。
- 选中项使用内发光，不只改变文字颜色。
- 右侧参数卡保持强边界感，避免和主工作区混在一起。
- 禁用项不隐藏，降低透明度并说明后续可用。

## 5. 禁止项

- 不把截图做成移动端或网页 landing page。
- 不把右侧全局参数移到顶部工具栏。
- 不在默认 UI 露出 Claude SDK / 运行底座 / IPC 等工程词。
- 不把批量和定时做成假可用。
