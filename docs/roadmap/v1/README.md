# 布谷AI内容工厂 v1 路线图

更新时间：2026-05-18
状态：Archived historical source
参考来源：用户提供的 5 张「光合引擎 - AI 电商图片工作台」截图

> 归档说明：本目录保留 2026-05 v1 阶段的历史设计记录，不再作为当前 Agent runtime 和打包架构事实源。当前主线以 `docs/roadmap/v2/` 与 `docs/roadmap/limeagent/` 为准：`Frontend -> Electron Desktop Host IPC -> Lime App Server JSON-RPC -> RuntimeCore / backend`，并随 Electron 包携带 Lime `app-server` sidecar 与 packaged external backend。

## 一句话目标

把布谷AI内容工厂 v1 做成 **AI 电商内容生产工作台**：用户选择已成型的产品知识库或个人 IP 知识库，上传产品图、参考图或视频后，通过提示词、预设模板和全局模型参数，生成文章、营销文案、电商产品图、海报图、详情页分区图、买家秀、视频拆解、复刻脚本和分镜视频队列。

```text
布谷AI内容工厂 v1 = 已成型知识库 + 产品素材输入 + skills 管理 / 编排 + 文章 / 图片 / 视频生成 + 预览 / 导出 / 历史
```

## 产品定位

- **面向用户**：电商运营、设计助理、短视频剪辑、商品营销团队。
- **核心对象**：已成型知识库、知识引用、文章草稿、产品图、参考图、视频素材、提示词、生成模式、全局参数、预览结果、生成日志。
- **首要场景**：单次处理一套已成型知识库和一组产品素材，快速产出可用于公众号 / 小红书 / 电商详情页 / 社媒海报 / 短视频复刻的内容资产。
- **设计参考**：保留截图中的桌面工作台结构、暗色霓虹视觉、左侧能力导航、中间工作区和右侧全局参数面板。
- **工程边界**：不直接 fork 截图产品；在 布谷AI Electron 技术栈下实现同类工作台体验。

## v1 内容工程主链

对照「深澜智能：AI内容工程化案例」，v1 主链不是直接从知识库跳到图片 / 视频，而是先把知识库转成可复用的提示词和场景资产：

```text
已成型知识库
-> 品牌 / 产品提示词包
-> 产品场景库
-> 文案 / 脚本 / 图片提示词
-> 图片素材
-> 视频提示词 / 图片转视频素材
-> 视频生成队列
-> 生成历史 / 素材库
```

说明：案例里图片和视频提示词都基于同一个知识库批量生成，文案和脚本也从场景库派生；图片素材是视频素材的重要上游，但视频也可以同时使用脚本、参考视频拆解和外部素材，不强行规定所有视频都只能由图片生成。

## 当前决策

1. v1 继续用 布谷AI 当前 Electron 技术栈，不切 Tauri。
2. 本条为历史决策：v1 曾计划由本地 SDK runtime 承担文本编排和能力调度；当前主线已废弃该路径，统一由 Lime App Server sidecar 提供 Agent runtime。
3. skills 是一等能力，必须有独立的 `skills 管理` 页面；生成主链里仍优先用「预设提示词」「生成模式」「拆解维度」表达，避免让普通用户理解工程概念。
4. 模型配置采用统一 API 端点和 API Key，分开配置文字、图片、视频模型。
5. 知识库是文章、图片提示词和视频脚本的本地事实源；v1 只接入已成型的产品型知识库和个人 IP 型知识库，做选择、导入、关键词检索和引用注入，不做策略分析和 AI 自动搭建知识库。
6. v1 需要从知识库派生品牌 / 产品提示词包和产品场景库，再驱动文案、脚本、图片提示词和视频提示词。
7. v1 先做单次处理；批量处理、并发、内联队列和定时任务进入后续版本。
8. 所有生成结果必须可预览、可导出、可追溯到输入素材、知识引用与参数。

## v1 非目标

- 不做完整多租户 SaaS。
- 不做团队权限、计费和云端素材库。
- 不做云端协作知识库、复杂向量数据库和权限继承。
- 不做竞品抓取、市场调研、用户差评采集、店铺现状诊断和策略报告生成。
- 不做 AI 自动搭建知识库；v1 只消费已经整理好的知识库文件或内置样例。
- 不做全平台自动发布。
- 不做复杂视频剪辑时间线。
- 不承诺所有截图中的模型名都在本地真实可用；模型列表由配置和 生成服务 返回决定。

## 完成定义

v1 可宣称完成需要同时满足：

- 图片生成能完成 `上传产品图 / 参考图 -> 选择模式 -> 输入提示词 -> 生成 -> 预览 -> 导出`。
- 文章生成能完成 `选择知识库引用 -> 选择文章类型 -> 生成大纲 -> 生成正文 -> 发布检查 -> 导出 Markdown`。
- 知识库能完成 `选择内置知识库 / 导入成型知识库 -> 识别产品型或个人 IP 型结构 -> 关键词检索 -> 选择引用 -> 注入文章 / 提示词 / 脚本生成`。
- 品牌提示词包能完成 `知识库引用 -> 视觉风格 / 品牌口吻 / 合规边界 / 平台约束 -> 图片和视频提示词复用`。
- 产品场景库能完成 `知识库引用 -> 场景卡 -> 文案 / 脚本 / 图片素材 / 视频素材`。
- 模型配置弹窗能保存统一 API 端点、API Key、文字 / 图片 / 视频模型。
- skills 管理能完成 `扫描 -> 查看详情 -> 安装内置 skills 到工作区 -> 启用 / 停用 -> 校验错误提示`。
- 视频复刻能完成 `导入视频 -> 选择拆解维度 -> 生成分析 -> 填新产品信息 -> 生成脚本 -> 生成分镜图占位 / 队列`。
- 右侧全局参数在图片和视频页面保持一致、可保存、可参与生成请求。
- 素材库 / 生成历史能记录文章、图片、脚本和视频队列结果，至少支持本地查看和导出。
- 关键空态、错误态、生成中、成功态、导出态都有明确 UI。
