# 布谷 AI v3 UI 蓝图

更新时间：2026-05-23  
状态：Draft

## 1. 设计原则

- 桌面优先，移动端可读。
- 站点不是 SaaS 后台，首页必须先表达品牌和价值。
- OEM 能力要藏在控制台和配置页里，不把主首页做成管理台。
- 案例、素材和下载要能快速扫描，不做重装饰卡片墙。

## 2. 首页

### 2.1 首屏

- 主标题：品牌内容工厂 / OEM 品牌站。
- 副标题：案例、素材、下载和自有控制台。
- 主按钮：预约诊断 / 开始使用。
- 次按钮：查看案例 / 下载客户端。
- 右侧：产品截图、下载卡或 OEM 站点示意图。

### 2.2 首页区块顺序

```text
Hero
-> 案例摘要
-> 素材能力
-> 下载入口
-> 平台 / OEM 说明
-> 登录 / 控制台 CTA
```

## 3. 案例页

案例页承担“可复盘的品牌结果”表达，不做纯图片墙。

页面结构：

- 顶部筛选：行业、租户、主题、状态。
- 中部卡片网格：行业 / 标题 / 结果 / 关键指标 / 媒体预览。
- 右侧详情：来源、标签、适用站点、更新时间。

卡片字段：

- 行业
- 标题
- 摘要
- 结果
- 指标
- 媒体引用

## 4. 素材页

素材页用于展示品牌可复用资产。

页面结构：

- 顶部分类：图片、封面、长图、下载包、预览图。
- 中部资产网格：缩略图、标题、标签、来源。
- 右侧详情：关联租户、引用来源、发布时间、下载链接。

素材卡需要支持：

- 快速预览
- 关联案例
- 关联下载包
- 查看来源

## 5. 下载页

下载页保留清晰的版本和平台入口。

页面结构：

- 平台卡：macOS / Windows / 预览包。
- 版本卡：当前版本、sha256、size、发布时间。
- 说明卡：下载来源、校验方法、兼容范围。

## 6. 登录页

登录页保持当前站点品牌一致，不跳到 LimeCore 原始控制台。

页面结构：

- 左侧：账号与权益说明。
- 右侧：密码登录 / 邮箱验证码。
- 下面：首次验证、忘记密码、帮助邮箱。

## 7. 控制台

控制台要做“用户控制台 + OEM 管理台”的组合，但视觉上仍然是当前站点品牌。

建议 Tab：

```text
账号
下载
权益
站点配置
案例管理
素材管理
发布记录
```

### 7.1 站点配置面板

- 域名和别名。
- 主题色和背景。
- 导航项。
- 首页区块开关。
- CTA 文案。

### 7.2 案例 / 素材管理面板

- 新建、编辑、发布、下线。
- 预览、复制链接、查看来源。
- 绑定租户和标签。

## 8. 组件建议

- 使用卡片、分段导航、筛选条和详情抽屉。
- 不在页面里重复嵌套卡片。
- 租户信息、发布状态和资源状态用轻标签表达。
- 关键操作使用按钮，不使用不可理解的装饰元素。
