# 布谷AI内容工厂 v2 大模型玩法矩阵

更新时间：2026-05-20
状态：Draft

## 1. 核心判断

v2 不能只围绕“知识库生成内容”设计。真正要做的是充分利用大模型的长上下文、多模态理解、结构化输出、风格反推、批量变体、工具调用、Agent 多轮协作和自我质检能力，把不同内容生产玩法收敛成可产品化的 SOP。

```text
输入源
-> 大模型玩法原子
-> 手工跑通
-> SOP 文档化
-> Prompt 固化
-> Skill 封装
-> 批量素材生产
-> 质检 / 打标 / 导出
```

这里的“玩法”不是功能按钮，而是一类可复用生产方法。知识库也不再是一个泛化输入源：品牌 / 产品知识库要先生成场景库，再生成提示词组；IP 知识库要先形成个人 IP 六层体系，再延伸到口播、文案、私域、产品化等运营场景。

## 2. SOP 来源分类

| 来源 | 是否必须知识库 | 核心输入 | 典型产物 |
| --- | --- | --- | --- |
| 文档知识库驱动 | 是 | IP / 产品知识库、用户意图 | 文案、Prompt、选题、脚本、合规边界 |
| 品牌场景库驱动 | 是 | 品牌 / 产品知识库、季节、人群、痛点 | 场景卡、图片 Prompt、图生视频 Prompt |
| IP 知识库驱动 | 是 | 访谈稿、课程大纲、工作坊记录、IP 素材 | 六层 IP 知识库、口播、私域、付费产品文案 |
| 对标反推 | 否 | 参考图、参考视频、竞品内容 | 同风格 Prompt、仿款图、拆解报告 |
| 产品资料驱动 | 否 | 产品信息、SKU、卖点表、手填 brief | 详情页、主图、卖点图、FAQ |
| 用户内容驱动 | 否 | 评论、私信、问答、差评、客服记录 | 痛点库、标题、选题、话术 |
| 历史素材驱动 | 否 | 已通过图片、视频、文案、Prompt | 风格模板、变体 Prompt、复用标签 |
| 混合增强 | 可选 | 知识库 + 对标 + 产品图 + 评论 | 高稳定商业素材 |
| 批量自动化 | 可选 | 模板、参数表、SKU 列表 | 大批量素材、manifest |
| 外部工具协作 | 可选 | Prompt、参考素材、导出素材 | 第三方视频、混剪包、导入素材 |

## 3. 输入源穷举

| 输入源 | 典型文件 / 数据 | 可触发玩法 | 是否需要先结构化 |
| --- | --- | --- | --- |
| 知识库文档 | DOCX、Markdown、TXT、PDF 转文本 | 读文档、提炼人设、提炼卖点、合规检查、Prompt 生成 | 不需要，先让 Agent 读原文 |
| 品牌 / 产品知识库 | DOCX、PDF、产品资料、检测报告 | 提炼卖点、抽取场景、生成 UGC 实拍提示词 | 先形成场景库 |
| IP 知识库素材 | 访谈稿、课程大纲、工作坊记录、旧文案、产品资料 | 构建 IP 六层体系、生成运营场景库 | 按六层完整度构建 |
| 场景库 | 场景卡、痛点场景、人群场景、季节场景 | 生成图片 Prompt、图生视频 Prompt、文案 Prompt | 已结构化 |
| 参考图 | 商品图、竞品图、小红书图、海报、详情页截图 | 风格反推、布局拆解、同风格生成、文字 OCR、质检 | 不需要 |
| 参考视频 | 爆款视频、本地视频、外部生成片段 | 镜头拆解、脚本反推、节奏分析、视频 Prompt | 不需要 |
| 产品图 | 白底图、场景图、模特图、包装图 | 主体保持、换背景、商品种草、图生视频 | 不需要 |
| 产品资料 | 手填卖点、规格、成分、价格、FAQ | brief 结构化、详情页、文案、Prompt | 可临时结构化 |
| SKU 表 | CSV、Excel、JSON | 批量主图、批量详情页、批量标题 | 需要字段映射 |
| 竞品内容 | 笔记、标题、详情页、广告语、截图 | 爆款结构拆解、差异化改写、风险规避 | 可临时结构化 |
| 用户反馈 | 评论、差评、客服问题、社群问答 | 痛点聚类、选题矩阵、异议处理话术 | 可批量聚类 |
| 历史成功素材 | 已通过图片 / 文案 / 视频 / Prompt | 反向沉淀、风格模板、标签、质量基准 | 需要资产索引 |
| 人工意图 | 用户一句话目标、限制、风格要求 | Agent 追问、Prompt 打磨、SOP 参数化 | 不需要 |

## 4. 大模型玩法原子穷举

### 4.1 长文档读取

玩法：

- 读取个人 IP 知识库。
- 读取产品项目知识库。
- 读取 FAQ / 案例 / 检测报告 / 专利材料。
- 从长文档里找口吻、观点、卖点、禁用表达。
- 按用户意图生成 Prompt，而不是只做摘要。
- 对文档进行章节导航、证据定位和引用回溯。
- 按平台抽取不同粒度：公众号要长逻辑，小红书要场景和感受，短视频要钩子和节奏。

适合产品化：

- 知识库问答。
- Prompt Pack 生成。
- 平台文案生成。
- 口播脚本生成。
- 选题方向生成。

### 4.2 文档结构化抽取

玩法：

- 从 DOCX / Markdown 临时抽取人设、卖点、案例、禁用表达。
- 把长文档转成 `ProductBrief`、`PersonaBrief`、`ComplianceBrief`。
- 从检测报告中抽证据点，生成可引用句式。
- 从 FAQ 抽出异议处理表。
- 从方法论文档抽出“可复用表达框架”。

适合产品化：

- 文档导入后的 Agent 摘要卡。
- 高频字段沉淀。
- 详情页模块变量。
- 质检规则来源。

边界：

- 结构化是运行后的沉淀，不是所有文档导入前的硬门槛。

### 4.3 多轮 Prompt 打磨

玩法：

- 用户给目标，Agent 先读资料再追问。
- 用户要求改平台、改风格、改目标人群。
- Agent 生成多个 Prompt 版本。
- 用户选中一个版本固化。
- 固化后沉淀为 Prompt 模板或 Skill。

适合产品化：

- Prompt 工作台。
- Prompt 版本管理。
- Prompt 一键转图片 / 视频 / 文案任务。

### 4.3.1 品牌场景库生成

玩法：

- 读取品牌 / 产品知识库。
- 按季节、人群、问题、空间、动作、情绪和镜头抽取场景。
- 例如从儿童免疫相关资料中抽取夏季空调、泳池揉眼、蚊虫叮咬、冷饮腹痛、室内外温差等场景。
- 每个场景保留来源引用、合规边界和输出用途。
- 用户确认后形成场景库。

适合产品化：

- 品牌知识库页。
- 场景库页。
- 小红书 / 抖音图生视频素材 SOP。

### 4.3.2 场景提示词生成

玩法：

- 从场景卡生成 10 组可直接复制的图片 / 图生视频提示词。
- 提示词必须具备 UGC 手机实拍、自然光、真实生活感、细节清晰、无 AI 感等约束。
- 支持同一场景多版本：客厅、儿童房、泳池边、户外公园、厨房等。
- 支持直接复制到外部图片 / 视频生成工具。

适合产品化：

- 提示词库。
- 视频 Prompt 页。
- 混剪素材包前置素材生产。

### 4.3.3 IP 知识库构建

玩法：

- 读取个人 IP 的访谈稿、课程大纲、工作坊记录、历史文案和产品资料。
- 构建六层 IP 知识库：身份锚定、价值观立场、声音语言、判断方法、内容素材、创作引擎。
- 输出完整度、缺口清单和 DOCX / Markdown。
- 后续延伸出口播、文案、私域、产品化和咨询回复场景知识库。

适合产品化：

- IP 知识库页。
- IP 运营场景库。
- 口播逐字稿、朋友圈文案、私域回复和付费产品文案 SOP。

### 4.4 提示词反编译

玩法：

- 从参考图反推图片 Prompt。
- 从参考视频反推镜头 Prompt。
- 从爆款文案反推文案结构 Prompt。
- 从已通过素材反推“为什么好”的生成规律。
- 将反推 Prompt 分成主体、场景、镜头、光线、构图、风格、文字、负面约束。

适合产品化：

- 参考图反推页。
- 成功素材一键转模板。
- Prompt 解释器。

### 4.5 对标图反推

玩法：

- 上传 3-10 张竞品图。
- 模型识别构图、光线、道具、文字、画幅、风格。
- 反推出同风格 Prompt。
- 用自己的产品图生成同级别素材。
- 输出多条 Prompt：真实使用、礼盒手持、功效场景、桌面种草等。

典型例子：

```text
参考图 + 产品资料
-> 反推 4 条小红书种草图 Prompt
-> 生成同等风格图片
```

是否需要知识库：不必须。知识库只用于增强卖点准确性和合规边界。

### 4.6 对标视频拆解

玩法：

- 上传爆款视频或视频链接。
- 拆解开头钩子、镜头节奏、卖点顺序、字幕结构、BGM 情绪、CTA。
- 生成新产品口播脚本。
- 生成分镜图 Prompt。
- 生成视频 Prompt。

适合产品化：

- 爆款拆解。
- 口播脚本复刻。
- 图生视频 Prompt。
- 混剪脚本包。

### 4.7 爆款文案结构拆解

玩法：

- 拆标题：数字、反差、痛点、利益、场景、身份。
- 拆正文：开头钩子、问题描述、证据、解决方案、行动建议。
- 拆评论区诱导：问题型 CTA、收藏型 CTA、私信型 CTA。
- 拆平台语气：小红书感受型、公众号论证型、视频号口播型、详情页卖点型。
- 输出“可复刻结构”，不复制具体表达。

适合产品化：

- 竞品笔记拆解。
- 标题库生成。
- 文案模板沉淀。

### 4.8 风格迁移

玩法：

- 保持产品主体不变。
- 迁移参考图风格。
- 迁移竞品海报布局。
- 迁移小红书种草语言。
- 迁移详情页视觉层级。

注意：

- 只迁移风格和结构，不复制品牌、Logo、具体版权元素。
- 需要质检“产品是否变形”和“文字是否可读”。

### 4.9 产品资料整理

玩法：

- 用户粘贴产品资料或上传产品知识库。
- Agent 整理产品称呼、卖点、规格、适用场景、禁用表达。
- 抽成可复用素材变量。
- 生成图文 Prompt 或详情页模块。

适合产品化：

- 产品信息卡。
- SKU 变量表。
- 卖点卡。
- 合规表达卡。

### 4.10 用户痛点聚类

玩法：

- 导入评论、差评、客服记录、社群问题。
- 聚类高频痛点、顾虑、误解、使用场景。
- 把用户原话改写成标题、开头钩子和 FAQ。
- 找出竞品没有覆盖的角度。
- 输出“痛点 x 人群 x 场景 x 产品卖点”矩阵。

适合产品化：

- 痛点库。
- 选题池。
- 异议处理话术。
- 详情页 FAQ。

### 4.11 选题矩阵生成

玩法：

- 从知识库、竞品、评论、搜索词里抽关键词。
- 生成关键词五层：品牌词、行业词、长尾词、场景词、热点词。
- 组合人群、场景、痛点、平台。
- 生成 100-500 个候选选题。

适合产品化：

- 小红书选题库。
- 公众号选题库。
- 短视频脚本选题库。

### 4.12 平台化改写

玩法：

- 同一个事实源改写成公众号长文。
- 改写成小红书笔记。
- 改写成视频号口播。
- 改写成 B 站深度稿。
- 改写成详情页模块文案。

核心：

- 不是换标题，而是换结构、语气、信息密度和 CTA。

### 4.13 角色模拟与目标人群改写

玩法：

- 模拟不同用户身份：宝妈、职场人、银发人群、专业用户、初学者。
- 用不同关注点重写同一卖点。
- 让 Agent 站在用户角度追问“为什么我要信”。
- 生成反对意见和回答。
- 输出不同人群版本的标题、文案和图片 Prompt。

适合产品化：

- 人群版 Prompt。
- 场景版脚本。
- 异议处理卡。

### 4.14 文案生成

玩法：

- 标题生成：爆款标题、SEO 标题、封面标题、详情页短标题。
- 正文生成：小红书笔记、公众号长文、知乎回答、B 站口播稿。
- 脚本生成：短视频口播、分镜脚本、直播切片讲稿。
- 商品文案：主图卖点、详情页模块、FAQ、CTA。
- 绿幕图文案：标题卡、卖点卡、金句卡、结尾 CTA 卡。

适合产品化：

- 文案工作台。
- 平台模板。
- 脚本分段。
- 绿幕文案图。

### 4.15 图片 Prompt 生成

玩法：

- 文案转图片 Prompt。
- 产品资料转商品图 Prompt。
- 参考图转同风格 Prompt。
- 详情页模块转画面 Prompt。
- 口播脚本转封面图 / 分镜图 Prompt。
- 生成主 Prompt、负面 Prompt、参数建议和审核规则。

适合产品化：

- Prompt 工作台。
- 图片生成页。
- 详情页素材 SOP。

### 4.16 图片生成变体

玩法：

- 同一产品换背景。
- 同一产品换使用场景。
- 同一产品换构图。
- 同一产品换光线和材质。
- 同一产品换节日主题。
- 同一产品生成封面图、海报图、主图、详情页局部图。

适合自动化前提：

- 产品主体清楚。
- 风格模板稳定。
- 质量标准明确。
- 有人工审核或自动质检。

### 4.17 局部编辑与二次修图

玩法：

- 替换背景。
- 去除多余物体。
- 改文字区域。
- 扩图。
- 统一色调。
- 把已生成图片改成平台比例。
- 对失败图生成“修复 Prompt”。

适合产品化：

- 图片精修二期。
- 审核驳回后的定向重生成。

### 4.18 详情页模块化

玩法：

- 把产品资料拆成详情页模块。
- 每个模块生成图文 Prompt。
- 生成首屏、卖点、功效、对比、使用场景、FAQ。
- 统一风格和字体层级。
- 将模块导出为图片任务和文案任务。

适合产品化：

- 电商详情页 SOP。
- 多 SKU 详情页批量生成。

### 4.19 批量变体

玩法：

- 同一产品换背景。
- 同一产品换使用场景。
- 同一 SKU 换颜色。
- 同一文案换 10 个标题。
- 同一图生 4 个构图。
- 同一脚本生成 5 个开头钩子。

适合自动化前提：

- 模板稳定。
- 输入输出边界清楚。
- 质量标准明确。
- 不涉及高合规判断。

### 4.20 参数化批量生产

玩法：

- SKU 表按行生成标题、主图 Prompt、详情页模块。
- 同一 Prompt 模板填充不同卖点、颜色、规格、价格。
- 对每行生成多个候选版本。
- 自动打分后只把高分产物送人审。
- 导出批量素材包和 manifest。

适合产品化：

- SKU 批量图。
- 详情页批量图。
- 节日活动图。

### 4.21 绿幕文案图

玩法：

- 从口播脚本抽标题卡、卖点卡、金句卡、CTA 卡。
- 生成绿幕 / 透明 / 纯色背景图。
- 交给第三方混剪软件批量叠加。
- 同时生成图层 metadata 和字幕文本。

适合产品化：

- 视频素材包 SOP。
- 混剪素材包导出。

### 4.22 视频脚本和分镜

玩法：

- 从产品资料生成口播脚本。
- 从参考视频反推脚本结构。
- 从长文拆成短视频脚本。
- 生成分镜：画面、字幕、镜头、时长、转场建议。
- 把每个分镜转成图片 Prompt 或视频 Prompt。

适合产品化：

- 视频素材包 SOP。
- 爆款视频拆解。
- 口播脚本复刻。

### 4.23 视频片段任务

玩法：

- 根据图片和 Prompt 生成 15 秒视频 Prompt。
- 可内部 API 生成，也可复制 Prompt 到 RunningHub / 第三方平台。
- 第三方生成过程脱离软件；生成后的视频文件可由用户手动导入。
- 统一进入素材库。

边界：

- 不做成片剪辑。
- 不做时间线。
- 不做自研混剪。

### 4.24 成品视频导入与复盘

玩法：

- 第三方平台生成视频后，用户可选拖回软件。
- 关联原视频 Prompt、参考图和平台参数。
- 自动打标签：产品、场景、镜头、画幅、时长、状态。
- 对可用片段反向总结 Prompt。
- 不可用片段生成失败原因。

适合产品化：

- 视频 Prompt 记录。
- 手动导入成品视频。
- 视频素材库。

### 4.25 素材智能匹配

玩法：

- 脚本分段。
- 每段匹配图片、视频、绿幕图、BGM 标签。
- 生成素材使用建议。
- 导出混剪 manifest。

适合产品化：

- 混剪包生成。
- 批量视频生产前置。

### 4.26 质检与评分

玩法：

- 检查图片中文字是否糊。
- 检查产品是否变形。
- 检查是否有医疗化 / 绝对化表达。
- 检查是否跑题。
- 检查是否像 AI 味。
- 给可交付评分。

输出：

- 通过。
- 驳回。
- 重生成建议。
- 人工抽检标记。

### 4.27 合规与事实校验

玩法：

- 检查绝对化、医疗化、功效承诺、侵权风险表达。
- 检查文案是否引用了知识库不存在的事实。
- 检查是否使用了竞品品牌、Logo、商标元素。
- 对高风险内容要求人工确认。
- 输出风险类型、位置、建议替换表达。

适合产品化：

- 发布检查。
- 素材审核台。
- Prompt 生成前的禁用规则。

### 4.28 自动打标

玩法：

- 对图片 / 视频 / 文案打平台标签。
- 打产品、场景、人群、风格、状态标签。
- 写入 sidecar JSON。
- 后续可写 XMP。
- 素材库按标签检索和复用。

### 4.29 Prompt 反向沉淀

玩法：

- 从成功图片反推 Prompt。
- 从成功视频反推镜头描述。
- 从审核通过的素材总结模式。
- 转成模板。
- 转成 Skill。

这是持续提高产能的关键：好结果不是一次性消费，而是回流到模板库。

### 4.30 SOP 自动草拟

玩法：

- 用户描述“我要做一个流程”。
- Agent 根据已有玩法原子生成 SOP 草案。
- 自动列输入、步骤、输出、质检、导出。
- 用户确认后进入 `WorkflowDefinition`。
- 高级用户再用 canvas 查看或轻编辑。

适合产品化：

- SOP 工作流管理。
- 玩法到产品的最后一公里。

边界：

- 自动草拟的 SOP 默认是草稿，必须人工确认。

### 4.31 Skill 封装

玩法：

- 把稳定 Prompt 和操作步骤封装成 Skill。
- Skill 描述输入、输出、适用场景和禁用场景。
- 在 Agent runtime 中按需调用。
- 失败后回到多轮调整，不直接隐藏错误。

适合产品化：

- 高稳定 SOP。
- 团队内部方法论沉淀。
- 复用楚川方法论中的固定生产动作。

### 4.32 外部工具人工交接

玩法：

- 复制 RunningHub 图生视频 Prompt。
- 导出混剪软件 manifest。
- 导出图片素材文件夹。
- 导出 CSV / JSON 参数表。
- 第三方生成后可手动导入成品文件。
- 记录 Prompt、平台、复制时间和产物来源，不跟踪第三方任务状态。

适合当前阶段：

- 视频 API 成本高时。
- 第三方混剪软件更成熟时。

## 5. 可产品化 SOP 组合穷举

### 5.1 无知识库：对标扒图 SOP

```text
参考图
-> 模型反推风格和 Prompt
-> 用户补充产品资料
-> 生成同风格图片
-> 人工筛选
-> 入库
```

适用：

- 小红书种草图。
- 竞品海报复刻。
- 详情页局部模块仿风格。

### 5.2 无知识库：竞品文案拆解 SOP

```text
竞品笔记 / 详情页 / 广告语
-> 拆结构和表达策略
-> 生成不侵权的新结构
-> 用户补产品信息
-> 生成标题 / 正文 / 图片 Prompt
-> 审核入库
```

适用：

- 小红书标题。
- 详情页模块。
- 公众号开头。

### 5.3 有知识库：品牌 / IP 内容 SOP

```text
知识库文档
-> Agent 读取
-> 用户意图多轮调整
-> Prompt / 文案 / 脚本
-> 生成素材
-> 审核入库
```

适用：

- 公众号。
- 个人 IP 小红书。
- 视频号口播。
- 专业内容输出。

### 5.4 有知识库：产品卖点 SOP

```text
产品知识库
-> Agent 提炼卖点 / 证据 / 禁用表达
-> 用户选择平台和人群
-> 生成文案 / 图片 Prompt / FAQ
-> 质检
-> 入库
```

适用：

- 产品种草。
- 详情页。
- 主图卖点。

### 5.5 混合：商业素材 SOP

```text
产品知识库 + 竞品参考图 + 产品图
-> Agent 整理卖点和限制
-> 模型反推参考图风格
-> 生成 Prompt
-> 图片 / 视频 Prompt
-> 质检 / 打标 / 导出
```

适用：

- 产品种草图。
- 详情页图。
- 视频素材包。

### 5.6 参考视频拆解 SOP

```text
参考视频
-> 拆镜头 / 钩子 / 字幕 / 节奏
-> 替换成自己的产品资料
-> 生成脚本和分镜 Prompt
-> 生成可复制的视频 Prompt
-> 可选导入第三方成品视频
```

适用：

- 爆款复刻。
- 视频号素材。
- 短视频混剪素材。

### 5.7 详情页模块 SOP

```text
产品资料 / SKU 表 / 参考详情页
-> 拆详情页模块
-> 生成每个模块文案和图片 Prompt
-> 批量生成
-> 质检文字和产品一致性
-> 导出详情页素材包
```

适用：

- 电商详情页。
- 多 SKU 详情页局部图。

### 5.8 绿幕文案图 + 混剪包 SOP

```text
口播脚本 / 卖点列表
-> 抽标题卡 / 卖点卡 / CTA 卡
-> 生成绿幕图
-> 匹配视频片段
-> 导出混剪 manifest
```

适用：

- 批量短视频。
- 第三方混剪软件。

### 5.9 批量：参数化生产 SOP

```text
模板 + SKU 表 + 风格参数
-> 批量填充 Prompt
-> 批量生成
-> 自动质检
-> 人工抽检
-> 入库 / 导出
```

适用：

- 批量详情页。
- 换背景。
- 换颜色。
- 节日活动图。

### 5.10 历史成功素材回炉 SOP

```text
已通过素材
-> 反推 Prompt / 风格 / 质量原因
-> 沉淀模板
-> 生成同系列变体
-> 质检和打标
```

适用：

- 形成品牌视觉资产。
- 把偶然成功变成稳定产能。

### 5.11 评论痛点选题 SOP

```text
评论 / 差评 / 客服问题
-> 聚类痛点和顾虑
-> 生成选题矩阵
-> 匹配产品卖点
-> 生成文案 / 图片 Prompt / 脚本
```

适用：

- 小红书选题。
- FAQ。
- 直播话术。

### 5.12 发布检查 SOP

```text
文案 / 图片 / 视频 Prompt
-> 检查事实、合规、风格、可读性
-> 输出风险位置和修改建议
-> 通过后入库
```

适用：

- 公众号发布前。
- 电商素材审核。
- 批量自动化抽检。

## 6. 玩法到工程对象的映射

| 玩法对象 | 工程对象 | 说明 |
| --- | --- | --- |
| 输入源 | `WorkflowInputSource` | 统一记录知识库、参考图、视频、产品资料、SKU、竞品内容。 |
| Agent 多轮会话 | `AgentPromptSession` | 记录用户意图、Agent 追问、引用和 Prompt 版本。 |
| Prompt 草稿 | `PromptDraft` | 未确认、已确认、已物化三种状态。 |
| SOP 定义 | `WorkflowDefinition` | 保存输入、步骤、审核和导出规则。 |
| SOP 运行 | `WorkflowRun` | 保存一次执行的输入、步骤、状态和错误。 |
| 产物 | `WorkflowArtifact` | 文案、图片、绿幕图、视频 Prompt、手动导入视频、manifest。 |
| 质检结果 | `ReviewReport` / artifact metadata | 保存风险、评分、建议和人工结果。 |
| 成功方法 | Prompt Pack / Skill | 从已验证结果反向沉淀。 |

## 7. 产品化优先级

| 优先级 | 玩法 | 原因 |
| --- | --- | --- |
| P0 | 对标图反推 Prompt | 不依赖知识库，最快验证价值。 |
| P0 | 文档知识库 Agent Prompt | 体现内容工厂底座。 |
| P0 | Prompt 工作台和版本化 | 所有玩法都要先沉淀 Prompt。 |
| P1 | 图片生成 + 质检 + 入库 | 当前最核心交付物。 |
| P1 | 素材打标和复用 | 解决规模化资产沉淀。 |
| P1 | 绿幕文案图 | 直接服务混剪链路。 |
| P1 | 历史成功素材回炉 | 把好结果变成可复制模板。 |
| P2 | 参考视频拆解 | 服务视频素材包，但依赖视频理解稳定性。 |
| P2 | 视频 Prompt 人工外部生成 | 降低视频 API 成本。 |
| P2 | 成品视频可选导入 | 让第三方生成的视频可进入素材库。 |
| P2 | 混剪 manifest | 服务第三方混剪软件。 |
| P2 | SKU 批量变体 | 需要先有稳定模板和质检。 |
| P3 | Canvas 编排 | 高级用户需要，但不是主路径。 |

## 8. 工程约束

- 每个玩法都要先支持手工模式，再考虑自动化。
- 每个玩法都要有输入、输出、质检和入库规则。
- 知识库不是所有玩法的必填项。
- 参考图 / 参考视频可以成为事实源。
- Prompt 草稿必须可编辑和版本化。
- 成功素材必须反向沉淀 Prompt 和标签。
- 未配置 provider 时必须 blocked 或 waiting external，不允许假成功。
- SOP 必须能被表单执行；canvas 只能作为高级编辑视图。
- 批量生产必须先定义失败处理和抽检策略。
- 竞品反推只复用结构和风格，不复制品牌、Logo、可识别版权元素。
