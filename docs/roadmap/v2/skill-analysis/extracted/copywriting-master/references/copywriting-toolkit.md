# 舒老师文案方法论参考库

## 经典案例库

### 案例1：葡萄酒（缺陷转化法）

**产品信息**：
- 因气候不佳而口感偏酸的葡萄酒
- 没人买，库存积压

**常规思路**：回避"酸"的口感，强调其他优点

**舒老师文案**：
```
气候让葡萄略微酸涩，
这一杯，共敬这一年的不完美。
```

**成果**：被罗振宇2023"时间的朋友"跨年演讲引用

---

### 案例2：胡萝卜（情绪词）

**产品信息**：
- 脆甜多汁的胡萝卜
- 需要打破"胡萝卜不好吃"的刻板印象

**常规文案**：
```
脆甜多汁，营养好吃。
```

**舒老师文案**：
```
脆甜的胡萝卜，你甚至开始把它当零食了。
```

**分析**："甚至"打破预期，好吃到可以当零食

---

### 案例3：钻戒（情感升华）

**产品信息**：
- 情人节钻戒
- 需要突出爱情的仪式感

**常规文案**：
```
璀璨钻戒，见证爱情
```

**舒老师文案**：
```
敬所有蓄谋已久的浪漫
```

**分析**："蓄谋已久"四个字，把求婚这件事的心理活动写出来了

## 舒老师核心金句

1. "不要站在产品的角度讲产品，而是站在消费者的角度讲故事。"
2. "形容词画面感最弱，动词画面感最强。"
3. "文案是一门科学，不是玄学。"
4. "文案人要在紧凑的生活间隙里远离文字。"
5. "农闲时犁地，打雷时拔枪。"
6. "人类的不完美，恰恰是人类的魅力所在。"
7. "文案从来都是一件快乐的事情。"
8. "千万不要去看教你写文案的书。"

## 受众分析七步法

### 步骤

1. **基础画像**：年龄、性别、职业、收入
2. **生活场景**：日常生活中的典型场景
3. **痛点识别**：遇到什么问题？
4. **需求挖掘**：想要什么？
5. **替代方案**：目前用什么解决？
6. **决策因素**：购买时考虑什么？
7. **情感诉求**：深层的情感需求是什么？

### 从标签到场景

| 标签化思维 | 场景化思维 |
|----------|----------|
| 25-35岁女性 | 下班后疲惫地挤在地铁里的职场妈妈 |
| 高收入人群 | 凌晨3点还在回复邮件的创业者 |
| 健身爱好者 | 周末早起去健身房打卡的年轻人 |

## 卖点管理

### 核心卖点只有一个

每次文案只聚焦1个核心卖点，其余作为支撑。

### 卖点分类

| 类型 | 说明 | 示例 |
|-----|------|------|
| 功能卖点 | 产品能做什么 | 充电5分钟，通话2小时 |
| 情感卖点 | 产品带来什么感受 | 这一杯，共敬这一年的不完美 |
| 场景卖点 | 产品在什么场景使用 | 凌晨2点下班，这里的灯还为你亮着 |

### 真实性验证

- 功能卖点：必须可验证
- 情感卖点：必须有合理的情感连接
- 绝不造假、绝不夸大

## 常见错误对照

| 错误类型 | 错误示例 | 正确示例 |
|---------|---------|---------|
| 形容词堆砌 | 极致美味的顶级享受 | 好吃到差点咬到舌头 |
| 产品视角 | 搭载最新骁龙处理器 | 同时打开20个应用也流畅如飞 |
| 陈词滥调 | 匠心打造，品质之选 | [根据产品特点定制] |
| 多卖点混杂 | 好吃又健康又方便 | 专注一个核心卖点 |
| 自嗨表达 | 开启美好新生活 | 具体场景+具体感受 |
