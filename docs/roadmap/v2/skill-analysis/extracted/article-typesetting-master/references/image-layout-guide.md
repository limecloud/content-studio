# 图文混排指导手册

> 图片不是"配图" | 图片是排版节奏的核心元素 | 放对位置比放好看的图更重要

---

## 图片在排版中的三大角色

```
角色1：视觉断点（Rhythm Breaker）
├── 功能：打断长段文字的视觉疲劳
├── 位置：每800-1200字插入一张
├── 要求：与上下文相关，不需要精美，清晰就行
└── 示例：流程图、截图、场景照片

角色2：信息载体（Info Carrier）
├── 功能：替代文字传达信息（图比文字效率高10倍）
├── 位置：在需要解释复杂概念的地方
├── 要求：信息量大、可读性强
└── 示例：对比图、数据图、流程图、示意图

角色3：情绪渲染（Mood Setter）
├── 功能：营造氛围，唤起情感共鸣
├── 位置：文章开头（首图）/ 关键情感段落
├── 要求：美观、有氛围感、与文章调性一致
└── 示例：场景照、插画、概念图
```

## 图片位置黄金法则

### 纵向位置（什么时候放图）

```
必放图的位置：
├── 📌 首屏（文章第一张图）：开篇300字内
├── 📌 章节切换处：大板块之间，用图做"章节封面"
├── 📌 复杂概念处：文字说不清时，一图胜千言
├── 📌 情感高潮处：金句/结论前后，用图强化感受
└── 📌 文末总结前：最后一张图做"视觉收尾"

建议放图的位置：
├── 数据/对比出现时（数据图/对比图）
├── 步骤/流程讲解时（流程图/步骤图）
├── 长段文字之后（视觉喘息）
└── 互动引导前（吸引注意力）

不要放图的位置：
├── ❌ 连续两张图之间没有文字（除非是图集）
├── ❌ 段落中间突然插图（破坏阅读流）
├── ❌ 与上下文完全无关的装饰图
└── ❌ 文章最后一句话之后（结尾应该是文字）
```

### 横向位置（图片怎么摆）

```
居中对齐（默认推荐）：
├── 适用：大部分配图场景
├── 效果：稳定、正式、有呼吸感
└── 代码：style="display:block; margin:0 auto;"

左对齐+右侧文字环绕（谨慎使用）：
├── 适用：小尺寸配图+简短说明
├── 效果：紧凑、信息密度高
├── 风险：移动端显示可能错乱
└── 建议：公众号/邮件中避免使用

全宽铺满（强冲击力）：
├── 适用：banner图、场景大图、章节封面
├── 效果：沉浸感、视觉冲击
└── 代码：style="width:100%;"
```

## 图片尺寸指南

### 按平台推荐尺寸

```
微信公众号：
├── 正文配图：宽度 1080px，高度按内容自适应
├── 封面大图：900×383px（2.35:1）
├── 封面小图：200×200px（1:1）
├── 二维码图：300×300px
└── 圆角建议：border-radius: 8px

小红书：
├── 首图（最重要）：1242×1660px（3:4）或 1242×1242px（1:1）
├── 内容图：同首图尺寸保持一致
└── 文字图：白底+大字，字号≥40px

知乎：
├── 正文配图：宽度≥1200px
├── 题图：推荐 1920×1080px（16:9）
└── 信息图/流程图：宽度撑满内容区

头条：
├── 正文配图：16:9 横版为主
├── 封面图：推荐 1280×720px
└── 三图模式：660×370px × 3
```

### 按内容类型推荐尺寸

```
产品图/截图：
├── 宽度：800-1080px
├── 比例：自适应（按实际内容）
├── 圆角：8px
├── 阴影：可选（box-shadow: 0 2px 12px rgba(0,0,0,0.1)）
└── 边框：可选（1px solid #eee）

数据图/流程图：
├── 宽度：撑满内容区（100%）
├── 背景：白底或浅灰底
├── 字号：图中文字≥14px（手机可读）
└── 导出格式：PNG（文字清晰）

场景图/氛围图：
├── 宽度：100%全宽
├── 比例：16:9 或 3:2
├── 质量：高清，不压缩
└── 圆角：0（全宽图不加圆角）

头像/icon：
├── 尺寸：60-120px
├── 比例：1:1
├── 形状：圆形（border-radius:50%）
└── 边框：可选（2px solid #fff + shadow）
```

## 图片与文字的间距规范

```
图片上方间距：
├── 接在段落之后：margin-top: 20-25px
├── 接在标题之后：margin-top: 15px
└── 接在另一张图之后：margin-top: 15px（不推荐连续放图）

图片下方间距：
├── 下方接正文段落：margin-bottom: 20-25px
├── 下方接图注：margin-bottom: 5px（图注紧贴图片）
└── 下方接标题：margin-bottom: 25-30px

图注格式：
├── 字号：13-14px（比正文小1-2px）
├── 颜色：#999999（比正文浅）
├── 对齐：居中
├── 间距：图片下方5px
└── 格式：可选加上 ▲ 或 △ 前缀
```

### HTML模板

```html
<!-- 标准配图+图注 -->
<section style="margin:20px 0;">
  <img src="[图片URL]" style="width:100%; border-radius:8px; display:block;"/>
  <p style="text-align:center; font-size:13px; color:#999; margin-top:5px;">
    ▲ 图注文字
  </p>
</section>

<!-- 带阴影的截图 -->
<section style="margin:20px 0;">
  <img src="[图片URL]" style="width:100%; border-radius:8px; display:block; box-shadow:0 2px 12px rgba(0,0,0,0.1);"/>
</section>

<!-- 全宽场景图（无圆角无阴影） -->
<section style="margin:25px 0;">
  <img src="[图片URL]" style="width:100%; display:block;"/>
</section>
```

## 配图数量建议

```
文章长度      │ 建议配图数    │ 视觉断点间隔
──────────────┼──────────────┼─────────────
<800字        │ 1-2张         │ 开头+结尾前
800-1500字    │ 2-3张         │ 800字左右/张
1500-3000字   │ 3-5张         │ 800-1000字/张
3000-5000字   │ 5-8张         │ 600-800字/张
5000字+       │ 8张以上       │ 600字左右/张
```

## 无图时的视觉替代方案

没有配图时，用以下元素充当"视觉断点"：

```
替代效果从强到弱：

1. 引用框/金句卡片（最接近图片的视觉冲击）
2. 数据卡片（数字+说明，有信息量）
3. 表格（结构化信息，视觉上是一个"块"）
4. 有序/无序列表（比纯文字有节奏感）
5. 代码块/灰底文字块（技术文常用）
6. 分隔线+emoji装饰（最弱但聊胜于无）
```

## 图文混排自检清单

```
□ 首屏300字内有视觉元素吗？
□ 超过1200字没有配图的段落存在吗？（不应存在）
□ 每张图片与上下文相关吗？
□ 图片和文字之间有足够间距吗？
□ 图片在移动端显示正常吗（不超宽/不模糊）？
□ 连续两张图之间有文字过渡吗？
□ 图注（如有）格式统一吗？
□ 图片大小/风格全篇统一吗？
```
