> 40套精选配色方案，覆盖行业×情绪×趋势三大维度。
> 每套包含：主色(60%)+辅色(30%)+强调色(10%)+正文色+次要灰+深色背景版。
> 融合 Pantone 2026 Cloud Dancer、WGSN/Coloro 2026趋势、全球设计社区实战验证。
> **适用引擎**：E01-E04 全部引擎的S4设计阶段

## 使用指南

### 配色公式（所有方案通用）

```
主色（60%）：大面积使用，定基调——标题、色块、章节页背景
辅色（30%）：支撑主色——浅色版背景、分隔区域、次要元素
强调色（10%）：点睛之笔——关键数据高亮、CTA按钮、图表重点
正文色：正文文字——深色背景用白色，浅色背景用深灰
次要灰：图注、来源、次要信息——低存在感但必须可读
深色背景版：封面/章节页/结尾页的深色方案
```

### 选色决策树

```
Step 1: 你的行业是什么？ → 第一章·行业配色
Step 2: 你想传达什么情绪？ → 第二章·情绪配色
Step 3: 想跟上最新趋势？ → 第三章·2025-2026趋势配色
Step 4: 不确定？ → 第四章·万能安全牌
```

## 五、数据可视化专用色阶

### 5.1 顺序色阶（表示程度/等级）

```
蓝色渐变（推荐通用）：
#EFF6FF → #BFDBFE → #60A5FA → #2563EB → #1E40AF

绿色渐变（增长/正面）：
#ECFDF5 → #A7F3D0 → #34D399 → #059669 → #065F46

红色渐变（风险/负面）：
#FEF2F2 → #FECACA → #F87171 → #DC2626 → #991B1B
```

### 5.2 分类色板（区分不同类别）

```
6色分类板（互不干扰）：
#2563EB(蓝) #DC2626(红) #059669(绿) #F59E0B(黄) #7C3AED(紫) #EA580C(橙)

4色分类板（清晰区分）：
#2563EB(蓝) #DC2626(红) #F59E0B(黄) #059669(绿)

对比双色（A vs B对比）：
#2563EB(蓝) vs #F97316(橙)
#059669(绿) vs #DC2626(红)
#7C3AED(紫) vs #F59E0B(黄)
```

### 5.3 图表配色铁律

```
1. 强调项用强调色，对比项用灰色——不要每个柱子一个颜色
2. 相关数据用同色系深浅——不要用彩虹色
3. 增长用绿、下降用红——不要反着来
4. 背景保持浅色——图表区域不要用深色背景
5. 数据标签直接标在图上——减少图例使用
```

## 六、配色禁忌

```
❌ 超过4种颜色（3色最佳，4色极限）
❌ 纯黑(#000000)做背景 → 用 #18181B 或 #1E1E2E
❌ 纯白(#FFFFFF)做背景 → 用 #FAFAFA 或 #F8FAFC 或 #F0EEE9
❌ 高饱和色做大面积背景（伤眼）
❌ 相邻色块色差过小（看不清边界）
❌ 图表用彩虹配色（杂乱无重点）
❌ 深色背景上用深色文字
❌ 浅色背景上用浅色文字
❌ 每页换一套配色方案
❌ 红绿并列（色盲不友好）
```
