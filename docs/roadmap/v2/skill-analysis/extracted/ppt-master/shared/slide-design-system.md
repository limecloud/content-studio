# 共享知识库 - 版式设计系统

> 好设计不是装饰，是信息的视觉秩序。设计服务于内容，不是替代内容。
> **适用引擎**：E01-E04 全部引擎的S4设计阶段

## 一、设计四原则（CRAP）

### 对比（Contrast）
```
目的：建立视觉层次，引导阅读顺序

PPT应用：
├─ 标题与正文字号差≥16pt（如标题36pt，正文18pt）
├─ 关键数字放大到60-72pt，让它成为视觉焦点
├─ 深色背景+浅色文字 或 浅色背景+深色文字，对比度比≥4.5:1
├─ 重要信息用强调色（Accent Color），次要信息用灰色

❌ 常见错误：标题28pt正文24pt → 看不出层次
✅ 正确做法：标题40pt正文16pt → 层次分明
```

### 重复（Repetition）
```
目的：建立一致性和专业感

PPT应用：
├─ 全局统一配色方案（主色+辅色+强调色）
├─ 全局统一字体组合（标题字体+正文字体）
├─ 统一的图标风格（线性 or 填充，不混用）
├─ 统一的页码/导航元素位置
├─ 统一的间距系统（元素间距用固定值）

❌ 常见错误：每页用不同颜色"增加变化"
✅ 正确做法：用同一套色系，通过布局变化制造新鲜感
```

### 对齐（Alignment）
```
目的：建立秩序感，消除混乱

PPT应用：
├─ 所有文字左对齐（标题可居中，但正文必须左对齐）
├─ 多个元素之间建立对齐线（看不见但存在）
├─ 图片/色块边缘与文字边缘对齐
├─ 页面留白对称：左右边距一致，上下边距一致

❌ 常见错误：随手摆放，看着"差不多"就行
✅ 正确做法：用参考线精确对齐，误差≤2px
```

### 亲密（Proximity）
```
目的：用距离表达关系

PPT应用：
├─ 相关内容靠近（标题和对应内容间距小）
├─ 不同内容组之间拉开间距
├─ 图片和图注靠近
├─ 用间距分组代替分割线

间距建议：
├─ 组内间距：0.2-0.3英寸
├─ 组间间距：0.5-0.8英寸
├─ 页面边距：≥0.5英寸
```

## 二、配色系统

> **完整配色库**（40套·行业×情绪×趋势）：加载 `shared/color-library.md`

### 配色公式（速查）

```
标准三色法：
├─ 主色（60%）：大面积使用，定基调
├─ 辅色（30%）：支撑主色，背景/分隔
├─ 强调色（10%）：关键数据、CTA、高亮

深浅搭配法（推荐）：
├─ 封面/章节页/结尾：深色背景+浅色文字
├─ 内容页：浅色背景+深色文字
├─ 强调色贯穿始终
```

### 选色决策快速通道

```
知道行业 → color-library 第一章（10个行业×2-3套/行业）
知道情绪 → color-library 第二章（5种情绪×2套/情绪）
要跟趋势 → color-library 第三章（2025-2026五大趋势系列）
不确定 → color-library 第四章（5套万能安全牌）
做图表 → color-library 第五章（顺序色阶+分类色板）
```

## 三、字体系统

### 字体层次标准

| 层级 | 用途 | 中文字号 | 英文字号 | 字重 |
|------|------|---------|---------|------|
| H1 | 封面标题 | 40-48pt | 44-54pt | Bold |
| H2 | 页面标题 | 32-36pt | 36-40pt | Bold |
| H3 | 章节/副标题 | 24-28pt | 26-32pt | Semi-Bold |
| Body | 正文 | 16-18pt | 16-18pt | Regular |
| Caption | 图注/来源 | 10-12pt | 10-12pt | Light/灰色 |
| Data | 大数字展示 | 60-80pt | 64-96pt | Bold |

### 推荐字体组合

| 场景 | 中文标题 | 中文正文 | 英文标题 | 英文正文 |
|------|---------|---------|---------|---------|
| 商务正式 | 思源黑体 Bold | 思源黑体 Regular | Montserrat Bold | Source Sans Pro |
| 科技现代 | 阿里巴巴普惠体 | 思源黑体 | Inter Bold | Inter Regular |
| 文化温暖 | 方正标雅宋 | 思源宋体 | Playfair Display | Lora |
| 极简风格 | 苹方 Medium | 苹方 Regular | Helvetica Neue | Helvetica Neue Light |
| 安全默认 | 微软雅黑 Bold | 微软雅黑 | Calibri Bold | Calibri |

### 字体铁律

```
1. 全局最多2种字体（标题一种+正文一种）
2. 正文绝不用衬线体的斜体
3. 同一页字号不超过4种
4. 行距设置1.2-1.5倍（PPT中偏大更好读）
5. 如果不确定，用"微软雅黑+Calibri"——永远不会出错
```

## 四、版式系统

### 12种核心版式

```
1. 全屏标题型
┌─────────────────────┐
│                     │
│     大标题居中       │
│     副标题          │
│                     │
└─────────────────────┘
用途：封面、章节页、金句页

2. 左文右图型（黄金比例）
┌──────────┬──────────┐
│          │          │
│  标题    │  图片/   │
│  正文    │  图表    │
│  要点    │          │
│          │          │
└──────────┴──────────┘
用途：核心内容页（最常用）

3. 左图右文型
┌──────────┬──────────┐
│          │          │
│  图片/   │  标题    │
│  图表    │  正文    │
│          │  要点    │
│          │          │
└──────────┴──────────┘
用途：核心内容页（制造变化）

4. 上标题下内容型
┌─────────────────────┐
│     标题             │
├─────────────────────┤
│                     │
│   内容区（图表/文字） │
│                     │
└─────────────────────┘
用途：数据页、流程图

5. 三栏并列型
┌───────┬───────┬───────┐
│ 标题  │       │       │
├───────┤       │       │
│图标   │图标   │图标   │
│标题   │标题   │标题   │
│说明   │说明   │说明   │
└───────┴───────┴───────┘
用途：三个并列要点、对比

6. 四格矩阵型
┌──────────┬──────────┐
│  格子1   │  格子2   │
├──────────┼──────────┤
│  格子3   │  格子4   │
└──────────┴──────────┘
用途：四象限分析、多项对比

7. 大数字展示型
┌─────────────────────┐
│                     │
│       72%           │
│   收入同比增长       │
│                     │
└─────────────────────┘
用途：关键数据、里程碑

8. 时间线型
┌─────────────────────┐
│ 标题                 │
│                     │
│ ●──────●──────●────● │
│ 2022  2023  2024  25│
│ 事件  事件  事件  事件│
└─────────────────────┘
用途：发展历程、项目计划

9. 半图铺底型
┌──────────┬──────────┐
│          │          │
│  全出血  │  文字区  │
│  大图    │  标题    │
│          │  正文    │
│          │          │
└──────────┴──────────┘
用途：情绪页、场景展示

10. 引用/金句型
┌─────────────────────┐
│                     │
│  "金句内容"          │
│        ——来源        │
│                     │
└─────────────────────┘
用途：权威引用、重要观点

11. 流程/步骤型
┌─────────────────────┐
│ 标题                │
│                     │
│ [1]→[2]→[3]→[4]    │
│ 步骤 步骤 步骤 步骤  │
└─────────────────────┘
用途：流程说明、操作步骤

12. 对比型
┌──────────┬──────────┐
│   方案A   │   方案B  │
│  ✅ 优点  │  ✅ 优点 │
│  ❌ 缺点  │  ❌ 缺点 │
│  💰 成本  │  💰 成本 │
└──────────┴──────────┘
用途：方案比选、竞品对比
```

### 版式轮换规则

```
铁律：不连续3页使用相同版式

推荐节奏：
P1 全屏标题（封面）
P2 左文右图（开场）
P3 大数字（震撼数据）
P4 三栏并列（三个痛点）
P5 左图右文（方案介绍）
P6 四格矩阵（功能展示）
P7 半图铺底（情绪过渡）
P8 ...

版式分配原则：
├─ 内容密度高 → 用分栏/网格版式
├─ 单个核心数据 → 用大数字展示
├─ 情绪转折点 → 用全屏/半图/金句
├─ 多项并列 → 用三栏/四格
├─ 流程/时间 → 用时间线/步骤
```

## 五、图文比与安全区

### 6:4图文比法则

```
每页视觉元素占比 ≥ 60%，文字占比 ≤ 40%

"视觉元素"包括：
├─ 图表/数据图
├─ 图片/照片
├─ 图标/Icon
├─ 色块/形状
├─ 留白（算作视觉的一部分）

检查方法：把文字全部删掉，页面是否还有"内容感"？
├─ 有 → 图文比达标
├─ 空了 → 视觉元素不足，需要补充

例外：
├─ 引用/金句页：文字可以占主体（但字号要大）
├─ 目录页：文字占比可以更高
```

### 8%安全区标准

```
版式网格：
├─ 安全区：上下左右各留8%（16:9约0.77英寸/4:3约0.6英寸）
├─ 内容区：84%画面
├─ 关键信息不要贴边，至少离边缘一个标题的高度
├─ 投影设备可能裁切边缘，安全区防止信息丢失

对齐规则：
├─ 正文/要点：左对齐（永远）
├─ 标题：左对齐为主，居中仅用于封面/章节页/金句页
├─ 多列内容：顶部对齐+等宽列
├─ 所有元素必须咬合网格线，误差≤2px
```

## 七、留白与呼吸感

### 图标使用规则

```
风格统一：全局用同一种风格
├─ 线性图标（Line）：轻盈、现代
├─ 填充图标（Filled）：醒目、稳重
├─ 双色图标（Duotone）：层次感

大小统一：同一页图标大小一致
颜色统一：图标用主色或辅色，不五颜六色
数量控制：单页图标≤6个

推荐图标源：Lucide、Feather、Phosphor
```

### 图片使用规则

```
质量要求：
├─ 分辨率≥1920×1080
├─ 避免明显水印/合成痕迹
├─ 风格统一（同一PPT的图片色调一致）

处理技巧：
├─ 加半透明色块（蒙版），上面放文字
├─ 裁剪为统一比例（16:9 或 4:3 或 1:1）
├─ 用出血放置（图片延伸到页面边缘）
├─ 如果图片质量不够 → 模糊处理做背景
```

### 图表设计规范

```
通用规则：
├─ 图表标题 = 结论（不是"Q3收入"，而是"Q3收入涨了47%"）
├─ 删除多余网格线、边框
├─ 用强调色高亮关键数据
├─ 数据标签直接标在图上，减少图例
├─ 保持适度留白，不让图表挤满整页

颜色规则：
├─ 强调项：用强调色
├─ 对比项：用灰色或辅色
├─ 如有多个数据系列：用同一色系的深浅变化
```

## 七、留白与呼吸感

### 留白量化标准

```
页面边距：≥0.5英寸（全出血图片除外）
标题与正文间距：≥0.4英寸
内容块间距：≥0.3英寸
页面填充率：≤70%（至少30%是留白）

计算方法：
如果你觉得"内容放不下了" → 说明内容太多，应该拆页
不是"怎么塞进去"，而是"该删掉什么"
```

### 信息密度控制

```
单页信息密度检查：
├─ 文字≤60字（汉字，标题除外）
├─ 要点≤4条
├─ 图表≤2个
├─ 视觉焦点=1个

如果超标：
├─ 文字太多 → 拆为2页 或 转化为图形/图标
├─ 要点太多 → 合并/删减 或 用动画分步展示
├─ 图表太多 → 一页一图表
```

## 八、动画与过渡建议

### 原则：克制是美德

```
动画使用原则：
├─ 功能性动画：揭示信息层次（如逐条出现）→ 允许
├─ 装饰性动画：旋转、弹跳、飞入 → 禁止
├─ 页面过渡：全局统一一种（推荐：淡入淡出）
├─ 速度：快速（0.3-0.5秒），不拖泥带水

推荐动画：
├─ 淡入（Fade In）：最通用
├─ 向上滑入（Slide Up）：现代感
├─ 依次出现（Appear by Paragraph）：讲述节奏

❌ 绝对禁止：
├─ 翻转、旋转、弹跳
├─ 文字逐字出现
├─ 3D效果
├─ 每页不同的过渡方式
```
