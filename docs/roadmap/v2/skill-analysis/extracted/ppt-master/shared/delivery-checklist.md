# 共享知识库 - 交付检查与演讲备注

> 完成PPT不等于完成任务。交付前的检查决定了80%的最终呈现质量。
> **适用引擎**：E01-E04 全部引擎的S5交付阶段

---

## 一、三层交付检查清单

### 第一层：内容检查

```
□ 每页是否只有一个核心信息？（一页一核心）
□ 逻辑线是否清晰？（能否用一句话串联所有页）
□ 文字是否精简到不能再删？（单页≤30字）
□ 每个要点是否≤15字？
□ 标题是否用动词/数字开头？（非"关于XX"式标签）
□ 数据是否准确？来源是否标注？
□ 图表是否标注了关键数字和"So What"结论？
□ 是否有开场钩子和结尾CTA？
□ 是否消除了自嗨内容？（受众不关心的删掉）
□ 换位思考：观众看完能记住哪三个点？
```

### 第二层：设计检查

```
□ 配色是否统一且≤3色？
□ 字体是否≤2种？层级是否清晰（标题>正文>注释）？
□ 图文比是否≥6:4（视觉元素≥60%）？
□ 边距是否留出8%安全区？
□ 所有元素是否网格对齐？（误差≤2px）
□ 留白是否充分？（填充率≤70%）
□ 是否避免了连续3页相同版式？
□ 每页是否有视觉焦点？
□ 图片质量是否足够？（无模糊/水印）
□ 整体节奏是否有起伏？（不是平铺直叙）
```

### 第三层：演示检查

```
□ 在投影/大屏上预览过吗？（小屏幕看着好≠投影看着好）
□ 最小字号在最后一排能看清吗？（≥16pt）
□ 动画/过渡是否流畅？
□ 嵌入的视频/音频能播放吗？
□ 字体是否嵌入？（换电脑不乱码）
□ 是否有备份方案？（PDF版本）
□ 翻页器/遥控器测试过吗？
□ 总时长是否控制在分配时间内？
```

## 二、演讲备注编写法

### 备注结构模板

```
每页演讲备注包含：

1. 开场过渡语（1句）
   "刚才我们看到了问题的严重性，现在来看我们的解决方案"

2. 核心口述内容（2-3句）
   - 用口语化表达，不是念PPT上的字
   - 补充PPT上没有的细节/故事
   - 强调这一页最想让人记住的一点

3. 停顿/互动提示（如有）
   [PAUSE] [看向观众] [提问]

4. 翻页信号（1句）
   "那具体是怎么做到的呢？我们来看下一页"
```

### 演讲备注写作原则

```
1. 口语化：写说的话，不是写文字
   ❌ "据数据显示，本季度营收同比增长47%"
   ✅ "看这个数字——47%的增长，这意味着什么？"

2. 补充不重复：说PPT上没有的内容
   ❌ 把PPT上的文字再读一遍
   ✅ 讲一个数据背后的小故事

3. 控制时长：每页备注口述不超过90秒（约200字）
   ├─ 内容页：60-90秒
   ├─ 数据页：45-60秒
   ├─ 过渡页：15-30秒
   ├─ 全屏视觉页：30-45秒

4. 标注时间锚点：
   "到这里应该是第8分钟左右"
```

## 三、时间分配参考

### 按场景时长建议

| 场景 | 典型时长 | 页数 | 平均每页 |
|------|---------|------|---------|
| 融资路演（首轮） | 10-15分钟 | 10-15页 | 1分钟/页 |
| 融资路演（深度） | 30-45分钟 | 20-30页 | 1.5分钟/页 |
| 工作汇报 | 15-20分钟 | 12-18页 | 1-1.5分钟/页 |
| 年终述职 | 20-30分钟 | 15-25页 | 1-1.5分钟/页 |
| 方案提案 | 30-45分钟 | 20-30页 | 1.5分钟/页 |
| 培训课件（1小时） | 50分钟+10QA | 30-40页 | 1-1.5分钟/页 |
| 知识分享 | 15-30分钟 | 15-25页 | 1分钟/页 |

### 时间分配公式

```
总时长 = 演讲时间 + QA时间 + 缓冲

一般原则：
├─ 演讲时间 = 总时长 × 75%
├─ QA时间 = 总时长 × 20%
├─ 缓冲 = 总时长 × 5%

页数估算：
├─ 演讲时间(分钟) ÷ 1.2 = 建议页数
├─ 例：15分钟演讲 ÷ 1.2 ≈ 12页
```

## 四、演讲稿全文生成

### 从备注到口播稿

```
演讲备注（每页3句以内）→ 演讲稿（完整口播文稿）

转化规则：
├─ 备注是"要点提示"，演讲稿是"逐字可读"
├─ 加入过渡语："接下来""让我们看""这意味着什么？"
├─ 加入互动语："大家想一下""你觉得呢？"
├─ 标注节奏：[停顿2秒] [语气加重] [看向观众] [手势指向屏幕]
├─ 标注时间锚点："到这里应该是第8分钟"

每页口播稿长度：
├─ 内容页：150-200字（60-90秒）
├─ 数据页：100-150字（45-60秒）
├─ 过渡页：30-50字（15-30秒）
├─ 全屏视觉页：50-100字（30-45秒）
```

### 演讲稿输出格式

```
━━━━━━━━━━━━━━━━━━━━━━
📄 第X页 | [页面标题]
━━━━━━━━━━━━━━━━━━━━━━
🎤 口播稿：
"[完整的口述文字，包含过渡语和互动语]"

💡 节奏提示：
[停顿] / [语气] / [手势] / [互动]

⏱️ 本页时长：X分钟 | 累计：X分钟
━━━━━━━━━━━━━━━━━━━━━━
```

```

├─ 文字内容（标题+要点，已精简到位）
├─ 视觉元素描述（图表类型/图片方向/图标需求）
├─ 特殊效果（深色背景/渐变/蒙版...）
```

## 六、Q&A准备

### Q&A预备清单

```
提前准备5-10个可能被问到的问题：

必备问题类型：
├─ 质疑型："你怎么证明这个数据？"
├─ 深入型："能展开说说技术细节吗？"
├─ 边界型："如果XX情况发生怎么办？"
├─ 竞争型："和XX相比有什么区别？"
├─ 落地型："下一步具体怎么执行？"

准备方式：
├─ 每个问题准备30秒的精炼回答
├─ 备几页附录幻灯片（不在主流程中，需要时快速跳转）
├─ 对不知道的问题，准备好"我会后续跟进"的表达
```

## 七、导出与兼容性

### 导出检查清单

```
□ 字体嵌入（文件→选项→保存→嵌入字体）
□ 导出PDF备份版本
□ 确认文件大小合理（邮件附件≤20MB）
□ 命名规范：[主题]_[版本]_[日期].pptx
□ 16:9 和 4:3 比例确认（匹配投影设备）
□ 视频/音频文件是否打包在同一文件夹

如果需要跨平台：
├─ 用系统自带字体（微软雅黑、Calibri）
├─ 减少动画复杂度
├─ 图片压缩至合理大小
└─ 测试在目标设备上打开
```
