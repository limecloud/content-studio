# E03 - 💡 提案引擎 | 产品发布/方案提案

> 让决策者在看完后说"就这么干"，而不是"再想想"。

---

## 适用场景

- 产品发布/上市发布会
- 客户方案提案/竞标
- 内部项目立项
- 策略方案提报
- 合作伙伴提案

---

## 核心方法论：决策推动逻辑

### 提案的本质是降低决策风险

```
决策者听提案时的心理防线：

防线1: "这个问题真的存在吗？"（痛点验证）
防线2: "你的方案真的能解决吗？"（方案可行性）
防线3: "为什么选你不选别人？"（差异化优势）
防线4: "风险大不大？会不会翻车？"（风险控制）
防线5: "落地难不难？要花多少？"（实施成本）

你的提案要逐层击破这5道防线。
```

### 提案黄金结构（15-25页）

```
第一幕：建立共识（为什么要做？）
P1  封面                    ← 方案名称+一句话价值主张
P2  背景/现状分析           ← 行业趋势/市场变化/用户需求
P3  痛点/问题              ← 当前的核心痛点（量化）
P4  目标定义               ← 本方案要实现什么

第二幕：方案呈现（怎么做？）
P5  方案总览               ← 一页说清整体方案
P6  方案详情-1             ← 核心模块/功能1
P7  方案详情-2             ← 核心模块/功能2
P8  方案详情-3             ← 核心模块/功能3
P9  技术/实现路径           ← 怎么做到的（可选）

第三幕：建立信心（为什么能行？）
P10 竞品/方案对比           ← 为什么选这个方案
P11 成功案例/数据验证       ← 已经验证过的证据
P12 客户评价/背书           ← 第三方认可（可选）

第四幕：消除顾虑（风险可控吗？）
P13 实施计划               ← 时间线+里程碑
P14 资源需求/预算           ← 投入多少
P15 预期效果/ROI            ← 回报分析
P16 风险与对策              ← 可能的风险+应对方案

收束：
P17 总结/行动建议           ← 下一步做什么
P18 联系方式/附录           ← 收束
```

## 关键页面内容规格

### P2-P3 痛点呈现（提案最关键的部分）

```
痛点展示三层递进法：

Layer 1：行业大趋势（建立紧迫感）
"数字化转型已成必然趋势，但70%的企业转型失败"

Layer 2：目标客户的具体痛点（建立共鸣）
"贵公司目前面临的3个核心挑战：
 ① 库存周转天数45天（行业平均28天）
 ② 线上线下数据割裂，无法统一运营
 ③ 人工下单错误率8%，每月损失约XX万"

Layer 3：不解决的代价（制造紧迫感）
"按当前趋势，明年预计将额外损失XXX万"

版式选择：
├─ Layer 1 → 大数字/全屏视觉
├─ Layer 2 → 三栏并列（3个痛点）
├─ Layer 3 → 对比型（现在 vs 不改变的未来）
```

### P5 方案总览（一页说清）

```
目标：让决策者在这一页就理解方案全貌

方案总览页模板：
┌─────────────────────────────────┐
│         [方案名称]               │
│     [一句话价值主张]             │
│                                 │
│  ┌─────┐  ┌─────┐  ┌─────┐    │
│  │模块1 │→│模块2 │→│模块3 │    │
│  │名称  │  │名称  │  │名称  │    │
│  │说明  │  │说明  │  │说明  │    │
│  └─────┘  └─────┘  └─────┘    │
│                                 │
│  核心价值：[3个关键指标]         │
└─────────────────────────────────┘

版式推荐：流程步骤型 或 三栏并列
```

### P6-P8 方案详情

```
每个模块/功能1-2页：

必备元素：
├─ 模块名称+一句话定位
├─ 核心功能点（3-5个，用图标+短语）
├─ 效果预期（量化）
├─ 可视化展示（产品截图/流程图/架构图）

展示技巧：
├─ 功能对应痛点：每个功能解决P3中的哪个痛点
├─ 用Before/After：展示使用前后的差异
├─ 用场景化描述：不说"支持智能推荐"，说"店员打开平板就能看到个性化推荐方案"
```

### P10 竞品/方案对比

```
对比策略：

A. 有明确竞品时：
├─ 对比矩阵（选3-5个核心维度）
├─ 你强的维度用✅高亮
├─ 诚实标注你弱的地方（但说明为什么不关键或有改进计划）

B. 无直接竞品/内部多方案时：
├─ 方案A vs 方案B vs 方案C（推荐方案高亮）
├─ 列出评估维度：效果/成本/风险/时间
├─ 给出推荐理由（不超过3条）

设计技巧：
├─ 推荐方案那一列用强调色边框
├─ 在表格上方就说清"我们推荐方案B"（结论先行）
├─ 对比维度选对你有利的角度（合理合法）

版式推荐：对比表格 或 四格矩阵
```

### P13 实施计划

```
必备元素：
├─ 分阶段计划（Phase 1/2/3）
├─ 每阶段：时间+目标+关键交付物
├─ 双方责任界定（谁负责什么）
├─ 关键里程碑/验收节点

展示方式：
├─ 甘特图/时间线
├─ 分阶段卡片（每阶段一个色块）
├─ 里程碑路径图

示例结构：
Phase 1（1-2月）：需求确认+系统配置
  → 交付物：需求文档/配置方案
  → 里程碑：系统上线测试环境

Phase 2（3-4月）：试点运行
  → 交付物：试点报告/优化建议
  → 里程碑：核心指标达标

Phase 3（5-6月）：全面推广
  → 交付物：全面部署/培训完成
  → 里程碑：全系统上线
```

### P15 预期效果/ROI

```
ROI展示方式：

方式A：投入产出对比
├─ 总投入：XXX万
├─ 预期年化节约/增收：XXX万
├─ 回本周期：X个月
├─ 3年ROI：XXX%

方式B：Before/After大数字对比
┌──────────┬──────────┐
│  Before  │  After   │
│ 45天周转  │ 28天周转  │ ↓38%
│ 8%错误率  │ 0.5%错误率│ ↓94%
│ 人工下单  │ 自动下单  │ 效率×5
└──────────┴──────────┘

方式C：价值积累曲线
├─ Y1节约XX万（投入>回报，但趋势向上）
├─ Y2节约XX万（投入<回报，开始盈利）
├─ Y3节约XX万（纯利润区间）

版式推荐：大数字对比 或 折线图
```

## 提案专属设计建议

### 配色策略

```
to 外部客户：
├─ 用客户的品牌色做辅色（表示尊重和定制化）
├─ 自己的品牌色做主色
├─ 或者用中性色系（靛蓝/石墨），不用任何人的品牌色

to 内部决策层：
├─ 公司品牌色
├─ 方案推荐部分用强调色突出

to 竞标：
├─ 专业感优先（深色系）
├─ 和竞品区分的视觉风格
```

### 提案的"推荐方案"突出术

```
当有多个方案时，推荐方案要视觉上最突出：
├─ 推荐方案用强调色边框/背景
├─ 推荐方案列放中间（视觉焦点位置）
├─ 在推荐方案列顶部加"★推荐"标签
├─ 非推荐方案用灰色/弱化处理
```

## 完整示例：企业数字化转型方案提案大纲

```
📋 PPT大纲 | XX企业数字化转型方案 | 18页 | 预计25分钟

🎯 核心信息：通过供应链数字化，帮助XX企业库存周转提效40%、运营成本降低25%
🎭 叙事框架：SCQA
📐 情绪弧线：渐进高潮型

P1  [封面] | 全屏标题
    → "XX企业供应链数字化转型方案" | [公司Logo]

P2  [行业趋势] | 大数字+说明
    → 零售行业数字化率仅35%，但数字化企业利润率高出2.3倍

P3  [痛点分析] | 三栏并列
    → 库存积压（周转45天）| 数据孤岛 | 人工错误8%

P4  [目标] | 大数字展示
    → 三大目标：周转≤28天 | 数据打通 | 错误率<1%

P5  [方案总览] | 流程步骤
    → 三大模块：智能补货→全渠道中台→自动化运营

P6-8 [方案详情] | 左文右图 ×3
    → 每个模块：功能+场景+预期效果

P9  [技术架构] | 架构图
    → 系统架构+接口说明（技术受众需要）

P10 [方案对比] | 对比表格
    → 方案A(轻量) vs 方案B(标准)★推荐 vs 方案C(全面)

P11 [案例] | 左图右文
    → "YY企业采用后：库存周转从42天降至25天"

P12 [客户评价] | 引用型
    → "这是我们合作过最专业的团队" ——YY企业CTO

P13 [实施计划] | 时间线
    → Phase1(2月) → Phase2(3月) → Phase3(2月)

P14 [预算] | 表格
    → 总投入XX万，分阶段付款

P15 [ROI] | Before/After大数字
    → 12个月回本，3年节约XXX万

P16 [风险] | 四格矩阵
    → 4个风险+对策

P17 [总结] | 居中聚焦
    → "现在行动，12个月后见效" + 三步启动建议

P18 [联系] | 联系方式
    → 项目负责人 + 联系方式
```

## 常见问题

| 问题 | 处理方式 |
|------|---------|
| 客户需求不明确？ | 先做需求诊断页（列出假设，请客户确认） |
| 竞标不知道对手方案？ | 用"行业常见方案"做对比参照系 |
| 方案太复杂一页说不清？ | 先总览页说框架，再分页展开细节 |
| 客户说"太贵了"？ | 强化ROI页+分阶段实施降低首期投入 |
| 技术细节要不要放？ | 看受众：业务决策者放少量，技术评审放详细 |
