# E01 - 🚀 路演引擎 | 商业路演/融资BP

> 让投资人在第3页就坐直身子，在最后一页就想约下次见面。

---

## 适用场景

- 种子轮/天使轮/A轮融资BP
- 商业计划书路演
- 投资人定向汇报
- 创业大赛/路演比赛
- 内部创新项目立项

---

## 核心方法论：投资人决策逻辑

### 投资人看BP的心理路径

```
投资人脑中的6个问题（按优先级）：

Q1: 这是什么？解决什么问题？（3秒判断——标题+副标题）
Q2: 市场有多大？值得投吗？（市场规模——TAM/SAM/SOM）
Q3: 你们的方案凭什么能赢？（壁垒/差异化）
Q4: 怎么赚钱？能赚多少？（商业模式+财务）
Q5: 团队靠谱吗？（团队经验+执行力证据）
Q6: 你要多少钱？用来干什么？（融资需求+用途）

你的BP必须在15页内回答完这6个问题。
```

### BP黄金结构（10-15页）

```
P1  封面                    ← 一句话说清你是谁、做什么
P2  问题/痛点               ← 制造共鸣："市场有个大问题"
P3  解决方案                ← "我们怎么解决的"
P4  产品/服务展示           ← 截图/Demo/核心功能（可视化）
P5  商业模式                ← 怎么赚钱
P6  市场规模                ← TAM → SAM → SOM（漏斗图）
P7  竞争分析                ← 差异化矩阵（为什么是你）
P8  Traction/里程碑         ← 数据证据（用户/收入/增速）
P9  增长策略                ← 怎么从现在到未来
P10 团队                    ← 核心成员+背景亮点
P11 财务预测                ← 3-5年收入/利润预测
P12 融资需求                ← 要多少、用途、里程碑
P13 联系方式                ← 收束
```

### 可选补充页（按需插入）

```
├─ 客户案例/背书（P7-P8之间）
├─ 技术架构/专利（P4之后）
├─ 合作伙伴/生态（P8之后）
├─ 退出策略（P12之前）
├─ 风险与对策（P11之后）
```

## 逐页内容规格

### P1 封面
```
必备元素：
├─ 公司名称/Logo
├─ 一句话定位（≤15字）："[动词]+[目标客户]+[核心价值]"
├─ 融资轮次（可选）
├─ 日期

设计：深色背景+品牌色，简洁有力
时长：10秒

示例标题：
✅ "用AI让中小企业客服成本降低70%"
✅ "下一代智能仓储解决方案"
❌ "XX科技公司商业计划书"（无信息量）
❌ "致力于打造行业领先的智能化平台"（空洞）
```

### P2 问题/痛点
```
必备元素：
├─ 目标用户面临的核心痛点（1-3个）
├─ 痛点的量化数据（"每年损失XX亿"）
├─ 用场景/故事让投资人"感同身受"

技巧：
├─ 用"你知道吗？"句式开场
├─ 数据 + 真实场景 > 抽象描述
├─ 痛点越具体越好，别说"效率低"，说"平均等待45分钟"

版式推荐：左文右图 或 大数字+说明
时长：60-90秒
```

### P3 解决方案
```
必备元素：
├─ 一句话方案描述
├─ 3个核心功能/价值点（用图标+短语）
├─ Before/After对比（可选但推荐）

技巧：
├─ 方案要直接对应P2的痛点
├─ 用用户语言，不用技术语言
├─ "我们做了X，所以用户可以Y"

版式推荐：三栏并列 或 对比型
时长：60-90秒
```

### P5 商业模式
```
必备元素：
├─ 收入模式（订阅/交易/广告/授权/...）
├─ 定价策略（价格锚点）
├─ 单位经济模型（CAC/LTV/毛利率）
├─ 已验证的数据（如有）

展示方式：
├─ 订阅模式 → 用表格展示套餐层级
├─ 交易模式 → 用流程图展示交易链路
├─ 混合模式 → 用饼图展示收入构成

版式推荐：流程图型 或 表格型
时长：60-90秒
```

### P6 市场规模
```
必备元素：
├─ TAM（总可及市场）→ SAM（可服务市场）→ SOM（可获得市场）
├─ 数据来源标注
├─ 增长率

展示方式：
├─ 经典漏斗图：TAM → SAM → SOM 递减
├─ 同心圆：最外圈TAM，最内圈SOM
├─ 大数字：3个大数字并排

⚠️ 常见错误：
├─ 只说TAM不说SOM（投资人会质疑）
├─ 引用不靠谱的数据源
├─ 市场太小（<10亿）不够性感，太大（万亿）不够可信

版式推荐：大数字展示型 或 漏斗图
时长：45-60秒
```

### P7 竞争分析
```
必备元素：
├─ 竞品对比矩阵（2-4个竞品）
├─ 你的差异化优势（用✅/❌标注）
├─ 护城河/壁垒说明

展示方式（推荐）：
├─ 二维矩阵图：X轴和Y轴选两个关键维度，你在右上角
├─ 对比表格：列=竞品，行=核心维度，你的列用强调色

⚠️ 千万不要：
├─ 说"我们没有竞争对手"（投资人不信）
├─ 把竞品全标❌只有自己全✅（不真诚）
├─ 选不值一提的竞品来衬托自己

版式推荐：四格矩阵型 或 对比表格
时长：60-90秒
```

### P8 Traction/里程碑
```
必备元素（有什么放什么，按优先级）：
├─ 收入/GMV数据及增速
├─ 用户数/客户数及增速
├─ 留存率/NPS
├─ 关键合作伙伴/客户Logo
├─ 里程碑时间线

技巧：
├─ 有增长曲线就展示增长曲线（向右上的线是最强说服力）
├─ 没有大数字就用增速（"MoM 30%增长"比"100个用户"好听）
├─ Logo墙是社会证明的利器
├─ 早期项目可以用里程碑时间线代替

版式推荐：折线图 或 时间线 或 Logo墙
时长：60-90秒
```

### P10 团队
```
必备元素：
├─ 核心团队成员（3-5人）
├─ 每人：照片 + 姓名 + 职位 + 一句话亮点
├─ 团队整体互补性说明

亮点怎么写：
├─ 行业相关经验："前阿里P8，10年电商经验"
├─ 专业背景："MIT CS博士，3篇顶会论文"
├─ 创业经历："连续创业者，上一家被XX收购"
├─ 避免无关信息："热爱跑步"（投资人不care）

版式推荐：三栏或四栏人物卡片
时长：45-60秒
```

### P12 融资需求
```
必备元素：
├─ 融资金额
├─ 资金用途分配（饼图或条形图）
├─ 预计达成的里程碑
├─ 出让比例（可选，谈判中可不放）

资金用途常见分配：
├─ 研发/产品：40-50%
├─ 市场/获客：25-35%
├─ 运营/人员：15-20%
├─ 储备金：5-10%

版式推荐：大数字+饼图 或 里程碑路径图
时长：45-60秒
```

## 路演专属设计建议

### 配色

```
推荐配色风格：
├─ 深色调（午夜商务/靛蓝专业）：高端、信任感
├─ 品牌色为强调色
├─ 封面+末页用深色，中间用浅色

避免：
├─ 过于花哨的配色（投资人要的是专业感）
├─ 纯白背景（太单调，缺乏品牌感）
```

### 特别注意

```
1. 第1页必须让人记住你："做什么"比"是谁"重要
2. 前3页定胜负：痛点→方案→Wow Moment
3. 数据页要有"So What"：不止是数字，要有解读
4. 团队页放倒数第2-3页：先卖方案，再卖人
5. 最后一页不要只写"谢谢"：给明确的下一步（约会面/发详细材料）
6. 控制在15页以内：投资人注意力有限
7. 准备长版（30页）和短版（12页）两套
```

## 完整示例：AI客服SaaS种子轮BP大纲

```
📋 PPT大纲 | AI客服SaaS融资BP | 13页 | 预计12分钟

🎯 核心信息：用AI让中小企业客服成本降低70%
🎭 叙事框架：SCQA
📐 情绪弧线：渐进高潮型

P1  [封面] | 全屏标题
    → "SmartCS：用AI让中小企业客服成本降低70%"
    → 种子轮融资 | 2024

P2  [痛点] | 大数字+说明
    → 3800万中小企业，80%还在用人工客服
    → 平均客服成本50万/年，回复等待45分钟

P3  [方案] | 三栏并列
    → SmartCS三大核心能力：智能应答/意图识别/无缝转人工
    → Before/After：45分钟→3秒

P4  [产品] | 左图右文
    → 产品界面截图 + 3个核心功能描述
    → "3分钟部署，零代码"

P5  [商业模式] | 表格型
    → SaaS订阅：基础版199/月，专业版599/月，企业版定制
    → LTV:CAC = 8:1

P6  [市场] | 大数字展示
    → TAM 5000亿 → SAM 800亿 → SOM 50亿
    → CAGR 25%

P7  [竞争] | 四格矩阵
    → X轴：部署难度，Y轴：AI准确率
    → 我们在右上角（易部署+高准确）

P8  [Traction] | 折线图+Logo墙
    → 上线3个月，200+付费客户，MoM 40%
    → 客户Logo墙

P9  [增长] | 流程步骤型
    → Phase1 PLG → Phase2 渠道 → Phase3 企业直销

P10 [团队] | 三栏人物卡
    → CEO(前XX产品VP) + CTO(前YY架构师) + CMO(前ZZ增长负责人)

P11 [财务] | 折线图
    → 3年预测：Y1 500万 → Y2 3000万 → Y3 1.2亿

P12 [融资] | 大数字+饼图
    → 融资1000万，研发50%/获客30%/运营20%
    → 12个月达到：1000客户+月收入200万

P13 [联系] | 居中聚焦
    → "期待与您深度交流" + 联系方式 + 二维码
```

## 常见问题

| 问题 | 处理方式 |
|------|---------|
| 没有收入数据怎么办？ | 用用户增长/留存/试点数据代替 |
| 市场数据找不到权威来源？ | 用行业报告+自下而上推算双重验证 |
| 团队背景不够亮眼？ | 强调行业经验年限+具体成就 |
| 竞品太强怎么办？ | 找到一个差异化切入点，做窄做深 |
| 15页放不下？ | 删减次要页面，把详细数据放附录 |
