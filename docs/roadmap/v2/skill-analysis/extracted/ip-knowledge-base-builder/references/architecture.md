# 六层知识库架构：详细构建标准

基于深澜智能多个真实IP案例实战提炼。

## 第一层：身份锚定层

**目标：** 让AI在任何场景下都能准确回答"这个人是谁"

### 1.1 基础档案

必须包含的字段（有则填，无则标⚠️）：

```
姓名：
IP名/常用称呼：
年龄/出生年：
籍贯：
现居地：
学历：
当前主营职业/身份：
公司/品牌名：
社交平台账号：
政治身份（如有）：
```

### 1.2 一句话定位

**格式要求：** 必须是"A里最B的，B里最A的"结构，或同等精度的对比定位句。

**标准：** 能让一个完全不认识这个人的人，30秒内理解这个IP的稀缺性。

**案例参考：**
- IP-A（大健康·茶园创业者）："卖货的人里最懂产业的，懂产业的人里最会卖货的"
- IP-B（小红书运营专家）："小红书里最懂生意的，做生意里最会玩小红书的"
- IP-C（大健康品类操盘手）："大健康创新品类孵化操盘手，用产业+科技+互联网的思维，连接企业与渠道"

**如果素材中没有现成的定位句：** 根据素材归纳，标注【推断】，并说明推断依据。

### 1.3 核心标签体系

输出格式：

```
身份标签：（职业/专业身份，如"小红书官方导师"）
成就标签：（可量化的成绩，如"操盘GMV过亿"）
人格标签：（性格特质，如"潮汕商业基因+曾国藩式打呆仗"）
生活方式标签：（如"50公里越野跑完赛者"）
差异化标签：（最让人记住的一个奇特标签，如"从不粉丝量判断达人"）
```

### 1.4 职业履历时间线

用表格输出：

| 时间段 | 经历 | 关键成果 | 离开原因 |
|--------|------|----------|----------|

**重点：** 失败的段落必须收录，失败是最有价值的IP素材。

## 第二层：价值观与立场层

**目标：** 让AI知道这个人会说什么、不会说什么、在什么问题上有鲜明立场

### 2.1 核心价值观（3-5条）

每条格式：
```
· [价值观名称]：[用这个人自己的语言描述] 【原声/推断】
  → AI应用：遇到[场景]时，基于这个价值观，应该说[方向]
```

### 2.2 立场与观点库

收录这个IP在核心议题上的明确立场：

- 对金钱的态度
- 对失败的态度
- 对合作/合伙人的判断逻辑
- 对行业的独特判断
- 对"成功"的定义
- 其他鲜明观点（凡是素材中有明确表态的）

### 2.3 边界清单（AI禁区）

列出这个IP**绝对不会说**的话、**不会做**的事：

```
【绝对禁区】
· 不会说的话：（如"不会说空洞的励志鸡汤，不会说'只要努力就能成功'"）
· 不会接的合作：（如"不接纯流量型合作，不接自己不认可的产品"）
· 不会认同的观点：（如"不认同'女性创业要低调'"）
```

## 第三层：声音与语言质感层

**目标：** AI输出内容时，读起来像这个人说的，而不是像AI写的

### 3.1 语言风格关键词

5-8个词精准描述这个人的表达风格：
（如：短句/直接/数据化/不装/有棱角/口语感/喜欢举具体例子）

### 3.2 高频词与口头禅

直接列举，附出处：

```
· "猥琐发育"—— 形容低调积累（深澜智能客户原话）
· "打呆仗"—— 稳扎稳打不追风口（深澜智能客户的曾国藩式表达）
```

### 3.3 标志性句式结构

列出这个人最常用的表达模式：

```
· 不是X，是Y：（"不是在卖茶，是在卖产业壁垒"）
· 数字开头：（"4个月，单场500万"）
· 反问式：（"你说傻逼不？"）
· 自问自答：（"为什么？因为……"）
```

### 3.4 金句库（20条以上为佳）

格式：
```
> "[金句原文]"
场景：[这句话在什么情境下说的]
用途：[适合用在什么类型的内容中]
```

### 3.5 类比与比喻偏好

这个人解释复杂道理时喜欢用什么类型的比喻？
（如：某IP爱用历史典故；某IP爱用家庭经历做类比）

## 第四层：判断力与决策逻辑层

**目标：** 让AI继承这个人的核心方法论，能代替他/她做出"这个人会怎么判断"的推理

### 4.1 核心方法论

每个方法论的输出格式：

```
【方法论名称】
一句话描述：
底层逻辑：
具体做法：（步骤/原则/框架）
反面案例：（什么是错误做法）
应用场景：（什么时候用）
【原声支撑】：[引用原话]
```

### 4.2 行业判断与洞察

这个IP对自己所在行业的独特判断：

- 行业最大的误区是什么
- 未来3年押哪个方向
- 哪些人会被淘汰，哪些人会胜出
- 自己和同行最不一样的地方

### 4.3 踩坑与复盘（最有价值的素材）

每个坑的格式：

```
【坑名】
经过：[简述发生了什么]
代价：[付出了什么成本]
根本原因：[复盘出来的真正原因]
教训：[现在遇到类似情况会怎么做]
```

### 4.4 选人/合作逻辑

这个IP怎么判断一个人值不值得合作/信任？
（这对AI生成商业内容非常关键）

## 第五层：内容素材库层

**目标：** 储备可以直接被AI调用的故事原材料

### 5.1 人生转折故事库

每个故事的标准格式：

```
【故事标签】：（如"国家奖学金被抢事件"）
发生时间：
核心情节：[尽量还原细节，包括对话、感受、环境]
转折点：[什么改变了]
意义：[这件事说明了主人公什么特质/价值观]
可用于：[什么类型的内容中可以调用这个故事]
情绪调性：[励志/反思/幽默/感恩/愤怒……]
```

### 5.2 关键人物关系图谱

影响这个IP成长的重要人物：

```
· [人物名/关系]：[他/她给了什么影响] → [AI调用建议]
```

### 5.3 客户/合作案例库

每个案例格式：

```
【案例标签】
背景：[客户当时的状态/需求]
做了什么：[具体操作，有数字最好]
结果：[量化结果]
关键决策：[最重要的一个判断]
可用于：[什么内容场景]
```

### 5.4 失败案例库

参考 4.3 踩坑格式，但侧重情感维度：

包含：当时的心理状态、恢复过程、现在的态度。

## 第六层：内容创作引擎层

**目标：** 让AI不只是"存储"这个人的信息，而是真正能"代替"这个人产出内容

### 6.1 多场景介绍话术

**30秒版（电梯 pitch）：**
[基于前五层归纳，直接写出来]

**2分钟版（直播/分享开场）：**
[包含：身份+核心成绩+方法论+一个小故事+定位句]

**合作/招商版（面向品牌方）：**
[包含：商业价值+人群覆盖+案例背书+合作方式]

### 6.2 内容创作SOP

告诉AI，基于这个知识库，创作不同类型内容时的标准流程：

```
朋友圈文案：
→ 素材来源：优先第五层故事库 + 第三层金句
→ 结构：[具体的开头-正文-结尾结构]
→ 长度：[字数范围]
→ 必须有：[这个IP的标志性元素]
→ 禁止出现：[第二层禁区]

视频号脚本：
→ 钩子来源：第五层转折故事
→ 干货来源：第四层方法论
→ 金句来源：第三层金句库
→ 时长：[建议时长]
→ 结构：[钩子-冲突-解决-升华]

客户咨询回复：
→ 判断依据：第四层判断力层
→ 立场参照：第二层价值观层
→ 语气参照：第三层声音层
```

### 6.3 禁区清单（汇总版）

把第二层禁区 + 这个IP绝对不会说的话，整理成AI可直接检查的清单。

### 6.4 AI应用指南

```
【适合作为系统提示词的核心段落】
[从本知识库提取最关键的2-3段，直接可以贴入AI系统提示词]

【推荐调用方式】
· 单次任务：[把知识库全文 + 任务要求一起输入]
· 长期使用：[把第一层+第二层+第三层+第六层存为固定系统提示，第四层+第五层按任务按需调用]

【效果验收标准】
· AI输出内容，能让认识IP本人的人说"读起来像她/他写的" = 合格
· AI输出内容，IP本人看完不需要大改 = 良好
· AI输出内容，IP本人直接发布 = 优秀
```
