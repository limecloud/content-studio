---

本 Skill 的核心使命：把任何形式的 IP 原始素材，炼成一份 AI 可以直接调用的结构化知识库。

---

## 一、触发后的第一步：素材诊断

收到素材后，**先做诊断，不要直接开始写**。

快速判断以下四件事，输出给用户看：

```
【素材诊断】
· 素材类型：（访谈文字稿 / 个人介绍文 / 聊天记录 / 简历+文章混合 / 其他）
· 字数估算：约 X 字
· 素材密度：高 / 中 / 低（"高"= 有大量原话、具体细节、数字；"低"= 主要是概述和标签）
· 明显缺口：（列出采集提纲中本次素材覆盖较弱的维度，不超过3项）
· 预计输出：约 X 字知识库（六层完整结构）
```

诊断完毕后，直接开始构建，不需要用户再确认。

## 二、六层知识库架构（必须完整输出）

详细的构建规则见 `references/architecture.md`。

六层结构概览：

| 层级 | 名称 | 核心目标 |
|------|------|----------|
| 第一层 | 身份锚定层 | 基础档案 + 一句话定位 + 核心标签 |
| 第二层 | 价值观与立场层 | 世界观 / 边界 / 不会说的话 |
| 第三层 | 声音与语言质感层 | 口头禅 / 句式 / 金句库 |
| 第四层 | 判断力与决策逻辑层 | 方法论 / 行业洞察 / 踩坑复盘 |
| 第五层 | 内容素材库层 | 人生故事 / 转折事件 / 客户案例 |
| 第六层 | 内容创作引擎层 | 智能体应用指南 / 场景话术 / 禁区清单 |

## 三、构建原则（每一层都必须遵守）

**原则一：原话优先**
能用原话就用原话，不要提前润色。原话加引号标注，来源注明"【原声】"。

**原则二：细节胜过概括**
"4个月做到双11单场500万"比"业绩优秀"有用100倍。数字、时间、地点、人名——能具体就具体。

**原则三：判断力比事件更重要**
记录"她当时为什么这么决定"比记录"她做了什么"更有价值。尽量还原决策逻辑。

**原则四：标注素材来源层**
每一段内容标注来源类型：
- 【原声】= 受访者原话
- 【推断】= 根据上下文合理推断
- 【待补充】= 素材中未提及，建议后续补充

**原则五：写给AI看，不是写给人看**
语言直接、结构清晰、避免文学性描述。AI需要的是判断依据，不是优美文字。

---

## 四、输出格式规范

- 使用 Markdown 格式
- 每层用 `## 第X层` 作为一级标题
- 每个子模块用 `### 模块名` 作为二级标题
- 原话用 `> 引用块` 格式
- 待补充项用 `⚠️ 待补充：说明缺什么` 标注
- 末尾输出【知识库体检报告】（见下文规范）

---

## 五、知识库体检报告（每次必须输出）

在知识库正文末尾，输出以下报告：

```
---
【知识库体检报告】

· 总字数：约 X 字
· 六层完整度：第一层 ✅ / 第二层 ✅ / 第三层 ⚠️ / 第四层 ✅ / 第五层 ⚠️ / 第六层 ✅
· 原声密度：高 / 中 / 低（原话占比估算）
· 最强维度：（哪一层素材最丰富）
· 最弱维度：（哪一层最需要补充）
· 建议补充采集：
  1. [具体缺失内容，用采集提纲的语言描述]
  2. [...]
  3. [...]
· 当前可支撑的AI任务：（列出当前素材可以让AI胜任的具体任务，如"朋友圈文案/视频号脚本口播/客户问题回复"等）
· 尚不支撑的AI任务：（列出当前素材不足以让AI胜任的任务）
---
```

## 六、特殊情况处理

**情况A：素材太薄（不足3000字）**
仍然按六层结构输出，大量标注 `⚠️ 待补充`，并在报告中给出具体的追问清单，让用户知道还需要采集什么。

**情况B：素材是多轮对话/聊天记录**
先提取有效信息段落，去掉寒暄和无关内容，再按六层归类整理。

**情况C：用户要求更新/升级现有知识库**
先阅读现有知识库，再阅读新素材，做差异比对，只输出新增/修改的内容，并说明改动原因。

**情况D：素材中有敏感内容（家庭变故/离婚/负债等）**
默认收录进知识库（加`🔒 内部素材，不对外输出`标注），不主动建议删除。是否对外公开由IP本人决定。

## 七、构建完成后

输出知识库正文 + 体检报告后，询问用户：

> "知识库初版完成。你可以：
> 1. **直接使用** —— 把这份知识库贴给AI智能体作为系统提示词
> 2. **补充采集** —— 我列出了缺失维度，你去追问IP本人后把新素材给我，我来补充
> 3. **生成话术** —— 基于这份知识库，我可以立刻生成30秒/2分钟/合作版介绍话术
> 4. **生成内容** —— 告诉我要写什么（朋友圈/视频号脚本/回复模板），我来生成"
