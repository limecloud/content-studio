无知识库对标图反推

US-01 / UC-03

上传小红书对标图和产品资料即可反推构图、光线、文字区域、风格，不要求用户先建知识库。

反推结果 构图：竖版 4:5，产品在右下三分之一；光线：窗边自然光；文字区：左上留白；风格：生活化、手机实拍、无 AI 感。

视频 Prompt 与第三方边界

US-05 / UC-08

软件生成 15 秒视频 Prompt，用户复制到第三方平台；第三方生成过程脱离软件，成品视频只能手动导入并关联原 Prompt。

主按钮：复制视频 Prompt 镜头：早餐桌近景，手拿条包入镜；动作：倒入水杯并放回书包；时长：15 秒；画幅：9:16；约束：不出现治疗承诺。

运行追溯、审核入库与混剪包

US-07 / US-08

普通用户不进旧 SOP 表单或 canvas。运行追溯保存输入源、对话、Prompt 版本、模型、产物和错误；审核通过后进入素材库并可导出混剪清单。
