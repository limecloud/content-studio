## 原型契约

PRD 映射：

- 角色：新媒体运营、电商运营、短视频运营、审核人员、剪辑人员、内容工程师。
- 用户故事：`US-01` 到 `US-16`。
- 用户用例：`UC-01` 到 `UC-18`。
- 主路径：品牌 / 产品知识库 -> 场景库 -> 提示词组、IP 知识库 -> IP 运营场景库、无知识库小红书扒图、视频 Prompt 外部生成、混剪素材包、内容制造批次和运行追溯。
- 验收标准：多源输入可追溯、品牌知识库可生成场景库、场景库可生成 UGC 实拍提示词组、IP 知识库可展示六层完整度、Agent 多轮生成 Prompt、无知识库对标反推、图片和文案真实生成状态、视频 Prompt 可复制到第三方、素材审核和混剪包导出、普通用户不依赖 SOP 表单或 canvas。

目标用户：新媒体运营、电商运营、短视频运营、审核人员、内容工程师。

产品形态：本地客户端 / Electron 桌面工作台，不是 SaaS 后台。原型必须保留当前版本的一级导航和用户习惯：图片、视频、文案、知识库、资产、管理。

用户目标：在同一个桌面工作台里完成“图片生成 -> 视频拆解 / 视频 Prompt -> 文章生成 -> 知识库 / 场景库 -> 素材库 -> 生成服务 / skill / 运行追溯”。输入源、品牌 / 产品知识库、IP 知识库、Prompt 工作台和内容制造批次是现有能力上的增强，不替换现有客户端主线。

主页面骨架：固定左侧导航、顶部项目上下文、中间主任务区、右侧来源 / Prompt / 参数 / 审核栏。导航必须优先贴合现版本：图片、视频、文案、知识库、资产、管理。

核心对象：品牌知识库、IP 知识库、场景库、场景卡、提示词组、输入源、对话、Prompt 草稿、内容制造批次、运行追溯、图片素材、文案素材、视频 Prompt、绿幕文案图、审核结果、素材库、生成服务配置、skill 草稿、混剪素材包。

统一状态：草稿、可运行、生成中、待审核、已复制外部、已完成、待配置。

禁用词：`external-package`、`waiting-external`、`RunningHub 任务包`、`回填任务`、`KnowledgeCitation`、`runtime`、`Context Run`、Agent 相关会话表述。

## 当前原型帧

本轮交付先重做 `image-generation`，按现有客户端截图迭代，同时把 v2 PRD 的核心能力压进同一个客户端工作台里，不再使用 SaaS 后台或独立 Prompt 中台骨架。

当前帧必须复用现版本用户习惯：

- 左侧：布谷AI品牌卡、工作区卡、图片 / 视频 / 文案 / 知识库 / 资产 / 管理导航。
- 左中：统一输入源、打标 / 固定、产品图、参考图、用户意图、Agent 多轮调整、启动渲染引擎。
- 中间：选择生成模式、AI 创建 / 导入 / 导出编辑、预览图 / 生成日志、图片预览大盘区、v2 PRD 主链路和核心能力卡片。
- 右侧：参数 / 日志、文字模型、图片模型、视频模型、生成数量、画幅、分辨率、质量、PRD 映射、已选知识引用、当前启用 skills。

本帧已经显式覆盖 v2 PRD 内容：

- `US-01 / UC-03`：无知识库素材拆解，不强制先选知识库。
- `US-02 / UC-02`：Lime App Server Agent 读 DOCX / Markdown，并基于用户意图多轮调整。
- `US-13 / UC-15`：品牌 / 产品知识库先生成场景库，再生成提示词组。
- `US-14 / UC-16`：从场景卡生成 UGC 手机实拍图片 / 图生视频 Prompt。
- `US-15 / UC-17`：IP 知识库六层体系，不混入品牌知识库。
- `US-05 / UC-08`：视频 Prompt 复制到第三方，第三方生成过程脱离软件。
- `US-07 / UC-11`：审核通过、驳回、重生成和入库。
- `US-08 / UC-12`：混剪素材包和混剪清单导出。
- `US-09 / UC-13`：早期 SOP / 工作流定义用例已退役；当前只保留 Prompt / Skill 草稿沉淀和运行追溯，不恢复客户端 SOP 表单或 canvas。

## 交互说明

`index.html` 现在是可点击原型，不再是单张静态画板：

- 左侧每个功能项都可以点击，并切换中间工作区与右侧 PRD / 状态栏。
- 原型按现有客户端切换布局：图片相关页面显示产品图 / 参考图 / Prompt 输入栏；视频、文案、知识库、资产和管理页面隐藏该输入栏，使用三栏工作台。
- 每个页面都有页面目标、PRD 映射、流程导轨、关键指标、核心对象、产物预览、状态和对象表。
- 页面内主按钮、次按钮和状态胶囊可点击，会显示原型操作反馈；真实实现时这些动作需要写入运行追溯。
- 所有页面仍共用现有客户端壳层：左侧导航、左中输入源 / 素材、中央工作台、右侧参数 / 来源。

已补齐的可点击页面：

- 图片：图片生成、拆解素材、场景提示词、绿幕文案图、合规检测、图片精修。
- 视频：视频生成、视频脚本、视频 Prompt、成品视频导入、混剪包导出、创意视频、自定义视频。
- 文案：文章生成、标题生成、脚本生成。
- 知识库：成型知识库、品牌 / 产品知识库、场景库、IP 知识库、输入源 / 文档转换。
- 资产：素材库、Prompt 工作台、运行追溯。
- 管理：skills 管理、Provider 设置。

后续要补的帧也必须在同一客户端壳层里迭代：

- `video-prompt`：视频拆解、脚本、视频 Prompt、复制到第三方、成品视频可选导入。
- `article-generation`：知识库 Agent 文章生成和发布检查。
- `brand-knowledge`：品牌 / 产品知识库抽取场景库。
- `ip-knowledge`：IP 知识库六层完整度和场景延伸。
- `asset-library`：素材库筛选、详情、复用和回炉。
- `skills-management`：Prompt / 成功素材沉淀为 skill 草稿。
- `run-trace`：运行追溯只展示来源、Prompt、模型、审核和交付物，不恢复工作流定义维护。

## 保留现有能力的判断

- 图片生成必须保留：它对当前用户直接有用，是素材生产最短路径，也是 v2 场景库和提示词组的下游主入口。
- 视频模块必须保留，但定位要调整：内部视频 API 成本高，不作为默认主路径；视频拆解、视频脚本、视频 Prompt、成品导入和混剪素材包对当前用户有用。
- 原型不应把 Prompt 工作台放成唯一第一入口。Prompt 工作台是增强能力，用于把未固化玩法跑通后沉淀为 Prompt Pack / Skill 或内容制造批次模板。
