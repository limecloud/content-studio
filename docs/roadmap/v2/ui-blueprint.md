# 布谷AI内容工厂 v2 UI 蓝图

更新时间：2026-05-20
状态：Draft

## 1. 成套原型契约

v2 UI 目标不是做一个 SaaS 后台或纯 canvas 工具，而是在现有 Electron 客户端上渐进升级成“运营可直接执行、工程师可高级编排”的内容素材工厂。

主页面骨架延续 v1：

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 左侧导航 │ 中间工作区                                               │ 右侧参数 / 来源 │
│ 图片 / 视频 / 文案 / 知识库 / 资产 / 管理 │ 生成 / 反推 / Agent / 审核      │ 模型 / 输入源 / 状态 │
└─────────────────────────────────────────────────────────────────────┘
```

v2 原型和实现必须保留当前客户端用户的肌肉记忆：图片、视频、文案、知识库、资产、管理仍是一级结构。Prompt 工作台、SOP、场景库、输入源、审核和 canvas 是增强能力，不应把当前可用功能整体挪成 SaaS 后台式导航。

## 3. 知识中台

知识中台不是单一资料库页面，而是分成品牌 / 产品链路和 IP 运营链路。

```text
品牌 / 产品链路
  品牌知识库 / 产品知识库
  -> 场景库
  -> 提示词库
  -> 图片 / 视频 Prompt / SOP

IP 运营链路
  IP 知识库
  -> IP 运营场景库
  -> 口播 / 文案 / 私域 / 产品化提示词
  -> 场景延伸知识库
```

### 3.1 品牌知识库页

必须体现：

- 原始文档：DOCX / Markdown / PDF 转文本。
- 品牌调性、产品事实、卖点、目标人群和合规边界。
- 场景抽取入口：按季节、人群、问题、空间和情绪生成场景库。
- 来源追溯：每个卖点和场景都能回到文档章节。

主按钮：`生成场景库`。

### 3.2 IP 知识库页

必须体现六层完整度：

- 身份锚定层。
- 价值观与立场层。
- 声音与语言质感层。
- 判断力与决策逻辑层。
- 内容素材库层。
- 内容创作引擎层。

右侧显示待补充缺口、原始素材、导出 DOCX / Markdown 和场景延伸入口。

主按钮：`构建 IP 知识库` 或 `生成场景延伸库`。

### 3.3 场景库页

场景库是 Prompt 前的中间层，不是 Prompt 文本列表。

场景卡字段：

- 人群。
- 触发问题。
- 时间 / 季节。
- 空间。
- 动作。
- 情绪。
- 镜头。
- 合规边界。
- 输出用途。

主按钮：`生成提示词组`。

### 3.4 提示词库页

提示词库展示从场景卡生成的可复制结果：

- 图片 Prompt。
- 图生视频 Prompt。
- 文案 Prompt。
- 绿幕文案图 Prompt。
- 负面约束。
- 适用平台和生成器。

主按钮：`复制 Prompt` 或 `发送到生成队列`。

## 4. SOP 执行页

普通用户默认进入 SOP 执行页，不进入 canvas。

```text
顶部
  SOP 名称 / 平台 / 目标产物 / 版本 / 当前状态

左侧
  输入字段
  输入源选择：品牌知识库 / IP 知识库 / 场景库 / 参考图 / 参考视频 / 产品资料 / SKU 表 / 竞品内容
  产品图 / 参考图 / 视频素材上传

中间
  步骤进度
  当前步骤表单
  生成结果预览

右侧
  Prompt 草稿 / Prompt Pack
  全局模型参数
  审核清单
  产物状态
```

关键状态：

- `草稿`：输入未完整。
- `可运行`：必填项已完成。
- `生成中`：步骤执行中。
- `待审核`：产物需要人工确认。
- `已复制外部`：视频 Prompt 已复制，第三方生成过程脱离软件。
- `已完成`：可入库或导出。

## 6. Prompt 工作台

Prompt 工作台是大模型玩法的主入口，优先服务“还没有固定 SOP，但要先把玩法跑通”的情况。

```text
左侧
  输入源与场景列表
  品牌知识库 / IP 知识库 / 场景库 / 参考图 / 参考视频 / 产品资料 / SKU 表 / 竞品内容
  上传 / 粘贴 / 选择历史素材

中间
  用户意图
  Agent 多轮对话
  场景卡
  Prompt 草稿版本
  对比 / 确认 / 物化为 SOP 或 Skill

右侧
  来源引用
  模型参数
  输出用途：文案 / 图片 / 视频 Prompt / 绿幕图 / SOP / Skill
  质检规则
```

关键能力：

- 品牌场景 Agent：读品牌 / 产品知识库后先生成场景库，再生成 Prompt。
- IP 知识库 Agent：按六层结构构建 IP 知识库，并延伸运营场景库。
- 拆解素材：看参考图和产品资料后生成图片 Prompt。
- 视频拆解：拆镜头、脚本、字幕和节奏。
- 产品资料整理：把 brief 转成变量和禁用表达。
- 成功素材回炉：从通过素材反推模板。

## 7. Canvas 编排视图

canvas 是高级模式，只服务内容工程师。

```text
画布
  节点：品牌知识库、IP 知识库、场景库、提示词组、输入源、Agent 读取、参考图反推、视频拆解、生成文案、生成图片、视频 Prompt、质检、审核、打标、导出
  连线：数据依赖
  分支：审核通过 / 驳回
  并行：多提示词、多图片、多平台导出

右侧属性面板
  节点名称
  步骤类型
  输入映射
  输出产物
  重试策略
  审核规则
```

限制：

- 不允许只有 canvas，没有 JSON 定义。
- 不允许普通用户必须拉线才能运行 SOP。
- 不允许 canvas 修改正在运行的 definition snapshot。

## 8. 审核台

审核台用于把候选结果变成可交付素材。

```text
顶部筛选
  平台 / SOP / 产物类型 / 状态 / 时间 / 标签

卡片内容
  预览图 / 文案 / 视频缩略图
  来源输入源 / 来源引用
  提示词
  模型和参数
  审核按钮

操作
  通过
  驳回
  重生成
  入库
  导出
```

审核原因建议：

- 产品不一致。
- 字体模糊。
- 文案不合规。
- 风格不匹配。
- 画面构图不可用。
- 可交付。

## 9. 视频素材页

视频页不做时间线剪辑，默认是素材任务管理。

│   ├── 视频提示词
│   ├── 参考图
│   ├── 时长 15s
│   ├── 画幅
│   └── 复制 Prompt
├── 内部 API
│   ├── 生成服务
│   ├── 成本提示
│   └── 生成

│   ├── 拖入视频文件

## 11. 绿幕文案图

绿幕文案图是视频素材链的优先能力。

输入：

- 标题。
- 卖点。
- CTA。
- 画幅。
- 背景类型：绿幕、透明、纯色。
- 字体风格。

输出：

- PNG / WebP。
- 文案元数据。
- 可混剪清单记录。

## 12. 右侧参数栏

右侧参数栏在 v2 中需要显示：

- 当前 SOP。
- 当前运行状态。
- 当前 Prompt 草稿 / Prompt Pack。
- 当前场景库 / 场景卡。
- 当前知识库类型：品牌 / 产品或 IP。
- 输入源数量和类型。
- 来源引用数量。
- 文本模型。
- 多模态理解模型。
- 图片模型。
- 视频生成路径。
- 视频 Prompt 复制状态。
- 审核清单。

## 13. 空态和错误态

| 场景 | UI 表达 |
| --- | --- |
| 未选择 SOP | 展示 SOP 模板库和最近运行。 |
| 未选择输入源 | 提示可选择知识库、参考图、产品资料或历史素材。 |
| 品牌素材 SOP 未选场景库 | 提示先从品牌 / 产品知识库生成场景库，或手动新建场景卡。 |
| IP 内容 SOP 未选 IP 知识库 | 提示该 SOP 需要 IP 知识库，不能用品牌知识库替代。 |
| 素材拆解未上传参考图 | 提示上传 1-10 张参考图。 |
| 多模态模型未配置 | 素材拆解步骤待配置，引导到设置 - 模型，不伪造分析。 |
| 图片模型未配置 | 图片步骤待配置，不显示伪图。 |
| 视频 API 成本高 | 推荐复制视频 Prompt 到第三方平台。 |
| 第三方视频未导入 | 不作为失败状态；保留可选导入成品视频入口。 |
| 审核驳回 | 展示原因和重生成入口。 |
